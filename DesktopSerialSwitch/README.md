# 小车监控开关

桌面入口：`C:\Users\Administrator\Desktop\小车监控开关.exe`。

1. 双击 EXE，先点“开启后台”。打开工具本身只读取状态，不启动后台。
2. 选择电脑上的 USB 串口，点“连接串口”。波特率为现有监控后台的 115200 / 8N1。
3. 点“打开本地网页”查看监控；需要远程查看时，再手动点“开启同步”和“打开公网网页”。
4. 用串口助手之前点“断开串口”。“关闭同步”只停止上传；“关闭后台”同时停止上传并释放串口。
5. 退出窗口时，若后台仍在运行，可以选择全部关闭或仅关闭窗口。

所有服务均由按钮手动开启。没有新增启动项、计划任务或 Windows 服务。旧的公网 CMD 和监控开机启动快捷方式已移至 `%LOCALAPPDATA%\RobotTreasureMonitor\legacy-launchers-20261027`，可恢复。

目前使用本机已有的 `E:\Python\pythonw.exe` 和桌面 `jiezhezuo` 里的 MapTimingLogger，不要移动该工程目录。EXE 内含静默启动辅助脚本，无需把脚本放到桌面；使用时会将辅助脚本释放至本机应用数据目录。日志位于 `%LOCALAPPDATA%\RobotTreasureMonitor\logs`，可点击“查看日志”。

公网同步的凭据继续使用已有的本机加密配置，未打包进 EXE。公网网页此前出现的访问拦截仍是独立问题，打开按钮不能保证该网络能访问。公网状态显示的是同步进程是否运行，并不冒充上传成功或车辆数据有效。

## 验证

- .NET Framework C# 编译通过，目标为 Windows GUI，不弹命令行窗口。
- `verification.json`：9 项生命周期检查通过，包括本地后台手动启动、默认串口断开、列举串口、公网同步启动/停止、停止同步保留本地服务、断开接口及关闭后台。
- computer-use 检查了实际浅色窗口、开启后台、刷新串口和关闭后台按钮。
- 未实际连接 COM 端口，未进行传感器或车辆实物测试。当前交付时服务关闭。

源码为 `Program.cs` 和内嵌 `desktop_monitor_host.py`；`build.ps1` 可在本机重新构建。进程启停只匹配本工程指定的两个 Python 脚本完整路径。
