# AI-1811 静止量程测试

2026-10-10：从已验证的 `Laser12B_AI1811_Raw_Uart_Test` 复制为独立工程，沿用其时钟、USART2只接收、中断入FIFO及8字节校验解析。旧工程未修改。

## 接线与打开工程

- 激光：V→3.3V，G→GND，T→PA3，R不接。按模块丝印核对。
- 日志：USART3 115200、8N1，PB10→USB转TTL或车载蓝牙的RX，GND共地；沿用已有日志链路。不要把激光T接入该日志口。
- 打开 `MDK-ARM/Laser14B_AI1811_Range_Test.uvprojx`，目标同名，ARM Compiler 5。
- 用户自行下载这个工程。启动即连续测距，不需要按KEY2；按键不会启动电机。
- `StationaryGuard_Init()` 在HAL初始化后、时钟和串口初始化前，将PC2/STBY拉低，并将PA1、PA2、PC6、PC7四路PWM引脚设为低电平GPIO。没有电机定时器启动和运动代码。上电复位到软件执行前的电平仍取决于板上电路；静止测距时保持车辆固定，避免旧运动固件仍在运行。
- 板载1.44寸TFT使用原整车固定接口：PB4=BLK、PB5=RS/DC、PB6=RST、PB7=CS、PB8=SCLK、PB9=MOSI。工程复用 `Gray12_MapFullRoute_Calibration_Test/Hardware/TFT.c/.h`，没有占用激光PA3或日志PB10/PB11。

## TFT显示

启动后屏幕标题为 `LASER RANGE`，每200ms更新一次：

- `DIST`：最新距离，单位mm；例如`DIST 1500`是1.5米。
- `CONF`：最新可信度。
- `GOOD`：最新帧是否通过距离与可信度筛选。
- `FR ... GOOD ...`：上一完整1秒窗口的正确帧数及GOOD帧数；启动第一秒为0。
- `LINK FRESH/STALE/NO_DATA`：近期有正确帧、超过200ms没有正确帧或从未收到正确帧。
- `VALID DATA`只表示最新帧通过程序筛选，仍不代表卷尺精度或检测到的就是小车。

串口仍输出逐帧及每秒完整统计，TFT用于现场快速观察。屏幕刷新限为5Hz，降低软件SPI刷新对USART2接收处理的影响。

## 串口观察

串口助手选择实际COM口、115200、8N1、无流控、文本显示；VOFA+使用RawData。接收窗口打开后复位STM32，应出现 `Laser14B_AI1811_Range_Test`。这能确认下载的是本测试固件。

每个校验正确的原始帧输出一行，以下仅为格式示例：

```text
LASER MS=1250 SEQ=50 DIST_MM=1500 CONF=85 GOOD=1 FW=101 GAP_MS=20
WINDOW MS=2000 DT_MS=1000 FRAMES=50 GOOD=50 MIN_MM=1490 MAX_MM=1510 MEAN_MM=1500 BAD_SUM=0 DROP=0 UART_ERR=0 MAX_GAP_MS=20 LINK=FRESH
```

- `DIST_MM`：模块返回距离，1500表示1.5米；保留超范围值，方便诊断。
- `CONF`：模块可信度。`GOOD=1`表示帧校验正确、50～4000mm、可信度10～100；这是本测试筛选条件，不证明测到了指定目标或测距准确。4000mm来自规格范围，不是本机已测得上限。
- `FRAMES/GOOD`：本窗口校验正确帧数/通过筛选帧数；`DT_MS`是实际窗口时长，不假定模块一定50Hz。
- `MIN/MAX/MEAN_MM`：本窗口GOOD样本统计。无GOOD样本时为0；单个MAX不能当作最远可用距离。
- `BAD_SUM/DROP/UART_ERR`：窗口内校验失败、FIFO丢字节、UART错误次数。
- `MAX_GAP_MS`：帧处理间隔或当前未收到数据的持续时间；时间由STM32提供，接收FIFO处理后打点，不是硬件边沿时间。
- `LINK=NO_DATA`从未收到正确帧；`STALE`距最后正确帧超过200ms；`FRESH`只表示有近期正确帧，仍须检查GOOD。低可信度帧可能使LINK保持FRESH。

## 实测最远可用距离

1. 模块固定在准备安装的高度，前方不要有地面、桌沿或墙面抢先进入视野；先用较大的平整白板作为目标，再换实际小车外壳或同材质、同大小目标。
2. 从传感器光学窗口到目标用卷尺测距。先测0.3、0.6、1.0米，再按0.5米增加；接近失效位置时改为每次0.1米。目标尽量正对模块。
3. 每个位置稳定不动至少10秒，记录实际距离、目标材质/尺寸、光照、串口日志。不要边移动边用最大值定量程。
4. 建议暂用“10秒内GOOD/FRAMES≥95%、没有超过200ms的断流、无持续校验或串口错误，读数接近卷尺距离且无明显跳变”作为初筛。帧率还应接近近距离测试时的稳定帧率，避免远距离只偶尔出帧而GOOD比例仍很高。准确度容差按策略需要另定。
5. 若遮住目标后仍显示同一距离，检查是否读到了后方墙面；改变目标位置确认读数跟随。分别记录白板最大稳定距离和实际车壳最大稳定距离。
6. 对实际车壳在正对及小角度偏转、室内与比赛光照下各重复至少3次，以较差结果设计策略余量。先重点验证目前策略需要的0.6米。

厂家本地 `JH-dT-1811-WU-V1.03.pdf` 第4页标称：90%反射率0.05～4米、10%反射率0.05～2米。不能直接把这两个数当成当前车壳或当前光照下的实测量程。激光只测距离，仍不能单独区分脚与小车。
