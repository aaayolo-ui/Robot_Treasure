N012不能直接跳到N031，实际必须经过N023；N061到N063之间存在真实三岔点N062，执行不能省略。固定计划通过BuildRoute保留所有可观察路口，不凭列表中省略的编号忽略灰度。前进/倒车起步均可；从西进入63时实际车头可能朝东或西，分别左/右转90°到北。

固定路线按用户指定，不宣称风险最优；KIND=5、DEGRADED=1明确区分固定路线与风险搜索。途中新的行进前方拦截仍优先制动、实测停稳再倒车巡线，回真实路口后按已有流程重规划。新规则替换此前N011北来车向西、南来车N012-N013偏好，不能同时保留相互冲突的约束。

新增停车转向只在N063实际横向到达、且计划最终方向为北时触发。先完成正常停车前180ms入中心并确认站稳，再捕获新鲜YAW，以相对角目标90°转动，避免依赖累计地图YAW基准。前70°复用普通主旋转的既有PWM动作，之后连续衔接既有轮速/陀螺仪控制，停止带5°；完成前仍确认实测停稳和新鲜角度，不给普通路口增加逐次±2°精调，也不增加中间前移/后退动作。实际角度和惯性需要实车验证，日志PARK_TURN_BEGIN/END用于对照。

旋转中地图姿态标无效，原始激光仍上传，但不把斜向回波投成旧车头方向。旋转结束后才发布北向姿态、清除旋转期间旧证据并重新开始四路确认。若旋转尚未开始、仍在停车等待阶段已确认敌车，原逃跑优先；如果已开始旋转，不因激光指令中途换行进方向冲出线。按键停车、真实陀螺仪失效和既有堵转处理保留。

4个生产改动文件：User/App_ThiefStrategy.c（仅新增专用停车动作及姿态/激光交接）；Algorithm/ThiefStrategy/ThiefMapPlanner.c（N011固定路线与N038出口）；ThiefRiskSearch.c（N038侧敌筛选上方目标）；ThiefInterceptPolicy.c（38停车轴）。16个Control文件、13个基础动作函数、普通巡线PID/轮速/速度、普通路口主转弯参数保持。N078临时避让、N038下方封闭环路过滤、下一路段坐标几何判断均保留。
