N078仅由63西侧遇敌规则显式选为临时目标，通用风险搜索不能把它当第六个藏点。普通路线经过78仍照常行驶。其纵向停车复用现有巡线、停车前入中心和停稳流程，不添加新的电机动作。

到78实际居中停车时，清除63携带的威胁模型、重规划方向锁存和请求，重置四路证据；帧时间必须晚于新节点的证据起点，仍需正常连续确认。不是收到一帧旧激光就返程。测试同时验证超过6秒无新威胁不出发，以及新北/西侧激光触发后整个实际ARM任务流到达后续藏点。
