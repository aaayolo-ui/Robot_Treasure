# 修改规范与回归清单

## 当前重建要求

小车巡线优先，取消主动冲出黑线/沿预测地图轴盲行找定位。正常动作以用户实测稳定的桌面16U RUN8为基线；不得为N001、宝藏区等单独添加行驶补丁，也不把Gray12不同速度/转角混进来。

每次修改源码、参数、状态机或工程配置前（同轮后续修改也一样）先读本文件和README，保留基线，核对实际固件标识。

1. RUN8的PID、平滑、四轮轮速控制、TravelFrame和普通转弯动作作为对照；任何必要差异单列，不能只对比PID数字。
2. 不导入MONITOR多层地图纠偏、逐次航向精调、100mm盲探/盲退及8候选行驶接管。
3. 位置估计只观察。LOC_DISTANCE/形状或地图航向不匹配可报告不确定，不能直接停车/旋转/关闭激光。固定路线导航不等于绝对定位，估计位置需明确标为ESTIMATED。
4. 路口动作仍以真实灰度触发；转弯中不能因逃跑直接交换帧。前后帧交换必须在实测停稳后执行。
5. 找线只复用一套基线灰度控制；允许后板实际线索参与，不允许双板白底时按地图轴前冲。连续双板无线2秒停车，真实I2C/陀螺仪异常和按键停车保留。
6. 保留正常速度与100RPM/180ms入中心、五藏点轴向。N011只允许西N010或东N012-N013；下方来车优先东、上方来车优先西，不加“两头被敌车堵住”专用分支。
7. 四路原始量程前后1000、左右800mm；场外过滤与取宝后启用规则保持。测距/串口监控与行驶控制分开验证。
8. ARMCC5编译、真实控制链离线测试、实际容量/栈检查必须绑定当前源码和AXF；不可用删断言或强设成功状态掩盖问题。
9. 新版是基于实测基线的软件重建，不能宣传本版已实车验证。未自动烧录/运行电机/占用串口/提交推送。

## 本轮验证状态

固件UARTCH4_16V_STABLE1，ARMCC5编译0错误、0警告。以下5组均绑定同一最终AXF，详见VALIDATION_STABLE1.json。

- test_stable1.py：375项检查；16个Control文件与RUN8逐字节一致，13个完整基础动作函数及正常巡线实际PID→平滑→四轮控制段一致。覆盖8种转向符号/倒车组合、双板白底2秒规则、定位观察失败不得操作电机、N011四种车身朝向×16种威胁掩码。
- test_escape_completion.py：25000项检查，40种藏点/朝向/激光触发与4种途中拦截完整模拟路线通过；结构无效边仍拒绝，定位观察器不同步不再否决合法起步。传感器和车体响应为合成模型，非实车证明。
- test_turn_resume.py：制动后恢复2例、连续驱动1例；test_left800.py：442项阈值检查；test_live_monitor.py：21项监控协议检查。
- 原始RUN8的LOC_DISTANCE停车用例已在原AXF复现并保存Reference/observer_before.json；新版保持有效线时不再被此类里程/地图航向入口中断。
- ROM63292字节、RAM44016字节；3KB栈包含在RAM中，剩余RAM5136字节。链接器已知调用栈896字节，未知调用/中断叠加尚未实测。

## 有意保留与必要差异

1. 100RPM/180ms入中心、正常速度、前后灰度切换、TravelFrame、45°主旋转→实际灰度接线→PID使用RUN8完整流程；不把MONITOR逐次地图轴精调放回去。宝藏屏蔽恢复RUN8原有N004↔N006文字侧外两路，不扩到N003～N007外四路。
2. 转动方向符号从实际陀螺仪转动和左右PWM独立学习，不依赖定位器提交成功。主旋转结束时前板实际无线就进入灰度恢复，取消无条件向前一拍。
3. 只留一套基线RestartLineSearch灰度恢复。允许实际后板线索参与；双板白底不沿地图轴前冲，连续2秒真实双板无线停车。真实陀螺仪/I2C故障、电机堵转、制动失败和按键停车仍保留。
4. 激光接收、AI1811配置、范围过滤共9个接口文件承接现有监控版，来源散列见Reference/ported_interfaces.json；未导入其复杂行驶控制器。
5. N011东西出口约束只在策略层实现。转弯中遇敌仍先制动处理，不能在尚未转好时直接换前后帧冲向无路方向。
6. 路线执行器以实际灰度路口推进，里程只记录不做强制否决。地图估计与定位观察器分开；LOC标STATUS=ESTIMATED、OBSERVER_ONLY=1、VALID=0，OBS_NODE单列，不能冒充传感器绝对定位。

## 未验证事项

新版未烧录、未实车验证。继承实测基线不代表本次整合已实测稳定；离线模型不包含实际惯性、灰度板安装偏差、轮滑和通信干扰。若真实漏认路口，路线估计仍可能错误，本版没有绝对重定位能力。首次实车应核对BOOT标识并保留完整串口日志，对照真实转弯、灰度和地图估计，不能仅凭网页轨迹判定坐标准确。
