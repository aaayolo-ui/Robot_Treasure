# 严格按正向基准迁移的倒车循迹试验

唯一行为基准为当前本地 `Gray12_SideTurn_LineFollow_Test`。应用源码直接从其 `User/App_LineFollowExperiment.c` 迁移，保留全部状态判断和调参值，仅替换传感器读取入口、轮速目标入口及工程启动名称。坐标映射集中在 `Control/ReverseRouteFrame.c/.h`。

## 传感器角色和左右定义

代码中的 FRONT/REAR 指行驶方向的前导/拖后角色：FRONT 读取物理后灰度，REAR 读取物理前灰度。启动日志 `START_FRONT` 因此表示物理后灰度；`FRONT_WAIT` 表示物理后灰度异常恢复。

所有左右判断以看向倒车行驶方向为参照。用户确认物理后灰度 P1 在原车头坐标的车左、P12 在车右；倒车坐标下 P1 就在右边、P12 在左边。基准的坐标转换和路口掩码因此保持原样：物理后灰度 P1+P2 触发倒车方向右转，P11+P12 触发倒车方向左转，全黑按倒车方向右转优先。

轮速映射为：物理左前=-虚拟右后、物理右前=-虚拟左后、物理左后=-虚拟右前、物理右后=-虚拟左前。直行四轮为负目标，位置纠偏同时交换左右并取反；原地转向旋转符号不变。原电机及编码器接线、引脚、驱动映射均保留。

## 启动和运行

- 后灰度 12 路全黑时按 KEY2 启动，向后以基准起步目标 100 RPM 离开起点。
- 后灰度看到普通有效线后，按基准保留轮速环切入循迹，不额外重新启停轮速 PI。
- 位置 PID 使用物理后灰度；物理前灰度连续有效时按基准规则加入航向 P。拖后板失效则按基准退回单前导板循迹。
- 直线基准 220 RPM，弯道最低基准 120 RPM；PID、300%/400%/400% 区域倍率、速度及差速斜坡均与正向基准文件相同。
- 路口监测仍为 5 ms，PID 仍为 20 ms。识别后以 100 RPM 倒车接近 200 ms，然后主动制动至少 80 ms，四轮编码器连续两次低于约 2 RPM 才允许开始转向。
- 陀螺仪阈值严格保留当前基准的 `ROUTE_TURN_TARGET_ANGLE_X100=5000`（测得 YAW 50.00 度），没有擅自改为 90 度。
- 转向后按基准进入直行找线，方向为倒车；看到可循迹线后恢复 PID。超时、失线、灰度通信错误、陀螺仪过期、堵转、按键停车均执行基准恢复或制动规则。
- KEY1、WK_UP 或运行中按 KEY2 停车；运行上限仍为基准 180 秒。

本轮严格迁移移除了先前倒车专用的中央区每帧 PID 重置、20 RPM 最小单轮倒转限幅、超过 8 路黑线拒绝规则、独立倒车状态机及红外介入。红外模块 GPIO 配置保留，但该纯循迹试验的应用不读取红外，也不由红外触发停车或切换。

## 调参和排查

速度与 PID：`Control/LineFollowPID.h`；平滑斜坡和弯道降速：`Control/FollowSmoothing.c`；路口延迟、制动、转向 PWM 和角度：`User/App_LineFollowExperiment.c`。此轮迁移未重新调整 PID。

直线突然原地旋转时，可观察 TFT：`TURN_LEFT`/`TURN_RIGHT` 表示进入了路口状态机；`FOLLOW` 状态下偏转则属于循迹差速。串口 `JUNCTION_DETECTED` 表示代码已触发路口判断，不能仅凭地图直线断言是 PID 问题。若全黑区刚离开就出现两端双黑的传感器图案，仍会按基准路口条件判定；本轮不改变基准判据。
