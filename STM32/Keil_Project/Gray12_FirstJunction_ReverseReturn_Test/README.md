# 首路口倒车返回测试

独立复制自 Gray12_SideTurn_LineFollow_Test 当前工作区源码，原工程未修改。没有增加硬件或改变引脚、时钟、串口、编码器、电机接线配置。

## 默认流程

1. 上电电机停止，前灰度置于全黑起始线，KEY2 启动；要求前后灰度初始化成功。
2. 按原逻辑前进循迹。第一个已解锁路口由前灰度最外侧双黑或全黑触发，立即主动制动，不执行原来的 200 ms 前进或该路口转弯。
3. 至少制动 80 ms，四轮编码器连续两次低于约 2 RPM 后才切换倒车；800 ms 仍未停稳则报错并保持制动。
4. 切换时物理后灰度必须读到普通有效线，否则保持制动，报 REVERSE_START_REQUIRES_REAR_LINE；若已经全黑，则直接 DONE。
5. 倒车时物理后灰度负责位置、路口和转弯保底；物理前灰度有效时提供双灰度航向修正。返程侧面路口仍执行原有接近、制动、YAW 转向、找线流程。
6. 倒车后每次领头灰度读到 0xFFF，立即主动制动进入 DONE。另有约 5 ms 检查，覆盖循迹、转弯、接近、找线和恢复状态。主循环及 I2C/TFT 耗时会影响实际检查间隔。
7. KEY1、WK_UP、运行中短按 KEY2 保留原停车逻辑。DONE 后保持制动，重新按 KEY2 才开始新一轮前进测试。

**地图约定：返程遇到的第一条全黑横线就是起始线。全黑路口与起始线仅凭灰度无法区分，因此倒车全黑优先停车，不执行全黑路口转弯。** 默认首路口折返测试主要验证直线倒车，倒车转弯需要另有侧面分支的测试路线验证。

## 倒车坐标与陀螺仪

以行驶方向为前方建立逻辑车体坐标。倒车时逻辑 FL/FR/RL/RR 对应物理 RR/RL/FR/FL，轮速映射为物理 `(-rr,-rl,-fr,-fl)`。后灰度 P12 为行驶方向左侧、P1 为右侧；前灰度作为尾随灰度时 P1 为行驶方向左侧、P12 为右侧。因此沿用原位置算法的领头/尾随安装参数，不重复翻转位序。

JY61P 的倒车行驶朝向为物理 YAW 加 180°并归一化；相对角变化和左右原地转向的旋转符号不变，不能直接将 YAW 取反。转弯目标仍为 50°，固定 PWM 500，沿用原来的新帧/超时/灰度保底逻辑。TFT 倒车期间显示的是行驶朝向 YAW。原程序没有直线陀螺仪锁航向，本工程直行也使用灰度位置与双灰度航向控制。

## 参数与日志

- 保留当前原工程参数：控制周期 50 ms，前进基准 100 RPM，Kp/Ki/Kd/Kh = 50/0/2/5（x1000）。原 README 的 20 ms / 220 RPM 不代表当前代码。
- 前进与倒车共用速度、循迹 PID、平顺控制、轮速 PI 和转弯参数。倒车不再额外限速或裁剪轮速，仅进行前后灰度角色与轮速坐标映射；转弯仍为 PWM 500、相对 YAW 50°。
- `FIRST_JUNCTION_BRAKE_FOR_REVERSE`：首路口制动。
- `TRAVEL=REVERSE LEADING=REAR TRAILING=FRONT`：已确认停稳并切入倒车。
- `RETURN_DONE REAR_RAW12=FFF`：后灰度全黑停车。
- `RETURN_REAR_I2C`：倒车领头后灰度通信异常，主动制动报错。
- 其余 FRONT/REAR 日志字段是逻辑领头/尾随，倒车时分别对应物理后/前灰度。
