# 四路激光原始距离标定测试

从同级 Thief16M_UARTCh4_InterceptEscape_Test 复制，原工程不修改。
打开 MDK-ARM/Laser_UARTCh4_RangeCalibration_Test.uvprojx。

上电即持续测距，无需按键、不需经过 N005；所有按键均不启动电机。应用仅调用电机初始化/关闭，不执行运动控制。
沿用当前已接通的四路扩展板接口 PB6 TX/PB7 RX、日志 PB10 TX、115200；TFT 保持关闭。
启动失败时保持静止，每隔3秒重新尝试初始化；初始化本身也需要等待时间。

## 查看与实测

烧录本工程生成的 HEX 后，使用原激光网页，选 COM9、115200。启动标识 FW=LASER_RANGE_CAL_3。
四路顺序 FRONT/LEFT/RIGHT/REAR，分别对应 CH1/CH2/CH3/CH4。每25ms轮流输出一路，每路10次/秒；网页每100ms轮询一次。
D 是传感器原始 mm，不套用1000mm策略上限，也不乘0.9。C 是原始置信度。
STATUS=RAW 表示该读数非零且置信度非零；不意味着测量已标定准确。
WAIT_DATA=未收到该路，STALE=该路超过500ms没新帧，BAD_DATA=距离或置信度为零，LINK_ERROR=初始化失败。
网页显示的是最近一帧，精度比较请同时看原始日志里的 RANGE 行。

每个 RANGE 行给出上一输出周期内的有效样本数 N、四舍五入平均值 MEAN_MM、MIN_MM、MAX_MM、排除样本数 REJECT。
每路统计窗口至少1000ms，首轮四路错开，因此长度略有差异；WINDOW_MS 为真实统计时长。
FRAMES 包含校验正确但距离/置信度无效的测距帧，HZ_X10 = FRAMES × 10000 / WINDOW_MS，四舍五入。
真实帧率是主控接收端的统计值，不是网页/串口打印频率，也不代表没有扩展板或链路丢帧。
无有效距离样本时 N=0，统计数值0表示没有统计数据；网页显示“—”。
零距离/零置信度仍会输出，但不纳入统计；校验失败帧不会被接收驱动送入统计。
BAD 为每路累计校验错误；DROP/ERR 是扩展板共享串口累计丢弃/错误，四路显示的是同一串口计数。

用平整不透光目标板，沿各传感器测量轴，从激光测距参考面量到目标面，保持同一材质、角度和光照。
建议分别记录100、200、300、500、700、900、1000、1500mm；每个点先稳定2秒，再保存至少5秒数据。
每次只移动一个方向的目标板，记录方向、尺量距离、均值、最小/最大值和置信度。
偏差 = 显示均值 - 尺量实际距离；正数是报远，负数是报近。
不要用车中心到目标的距离代替传感器到目标的距离，否则会混入安装偏移。

可选：在 User/App_LaserRangeTest.c 顶部 actual_mm 数组填入四路实际距离（前/左/右/后），重新编译后会增加 RANGE_ERROR。
也可以直接在网页各路卡片填尺量实际距离，实时计算“均值偏差”，输入只保存在当前浏览器，不向小车发送命令。
旧版 CAL_1 统计可显示均值，但没有 WINDOW_MS/FRAMES，网页不会推算Hz；须烧录新版固件才能显示准确帧率。
0 表示未指定，不输出误差；参考值只参与计算误差，不改变原始距离。

## 验证

用户三格参考（每格300mm）：左右原始读数800±50mm、后750±50mm。
网页车中心估距近似为左右原始均值+100mm、后+150mm，标注±50mm；前方未标定。
这只是单点安装偏移估计，不是全量程比例校准。原始值、尺量偏差仍按传感器参考面计算。
本轮未修改16M策略的0.9投影换算；网页中心估距不参与主控策略。
115200波特率和传感器主动上报设置不变，只提高主控上传频率。
