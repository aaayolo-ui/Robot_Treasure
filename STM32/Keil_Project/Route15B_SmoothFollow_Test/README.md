# Route15B 平顺循迹试验工程

从 `Route15A_TwoRightTurn_Stop_Test` 独立复制。保留原有双灰度、四轮速度 PI、两次右转后停车和故障停车流程；仅在循迹控制输出到车轮目标转速之间加入 `Control/FollowSmoothing.c`。

新增的三个功能在 `FollowSmoothing.c` 顶部各有独立开关：

| 功能 | 当前初始参数 | 作用 |
|---|---:|---|
| 基准速度斜坡 | 每 50 ms 增加 2 RPM | 循迹启动与转弯后恢复时逐步加速 |
| 按偏差降速 | 偏差 100～300 时从 40 降到 30 RPM | 大偏差时降低基础速度 |
| 转向修正变化率限制 | 每 50 ms 最大变化 2 RPM | 限制左右轮差速突变 |

上述参数仅是编译试验的初值，尚无实机调参依据。停止、传感器失效和堵转仍走原工程的立即停车路径；平顺模块只处理有效循迹样本。转弯阶段沿用原工程控制，未加入旧项目的 IMU 圆弧转弯。

建议依次单独验证基准速度斜坡、偏差降速、转向变化率限制，再验证三者组合；记录直线摆动、弯道越线、路口识别与转弯后找线情况。实机前需按现有工程安全流程核对供电和接线，不把本工程的编译结果当成硬件验证。
