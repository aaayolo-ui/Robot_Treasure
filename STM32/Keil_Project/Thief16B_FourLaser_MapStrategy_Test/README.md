## 检测和逃跑

- 四路均为 115200、8N1，每路独立 FIFO、校验、重同步、错误计数和接收时间戳，互不混用。
- 共用原 `FrontLaserGate.c`：50～600 mm、置信度≥10、5帧窗口至少3帧有效、有效距离跨度≤120 mm，并通过当前节点道路投影与场地边界过滤。
- 四路各有一份过滤状态。方向按车头换算：前0°、左−90°、右+90°、后180°，不会将侧后目标误投到车头前方。
- 超过250 ms没有新有效校验帧显示 `NO_DATA`；新数据到来时先清除旧投票。过期的队列字节不用于触发逃跑。串口溢出/错误会清队列并清除该路证据。
- 沿用前激光阶段限制：拿宝藏和逃跑移动期间关闭四路接收；到藏点且轮速稳定停下后重新接收，再检测、逃跑到下个藏点。不宣称行驶中四方向避障。
- 前方触发时起步方向避开前方，后方触发时避开后方。侧方触发在可用的前进/倒退路线中选择下个藏点，不新增原地90°转向起步。多路同时触发时，禁止向任何已确认威胁方向起步；前后均被堵或无可用路线时停住并输出 `ESCAPE_PLAN_FAILED`，不会盲目前冲/倒退。
- 策略只使用已有地图与有限测距；测到物体不等于识别了警方身份，继续沿用前激光的几何过滤规则。

原宝藏路线、速度、PID、转向参数和电机映射由复制时的16A保留。USART1/2/UART4在运动前关闭并复位，避免额外改变既有运动期外设状态；USART3只暂停接收，PB10日志发送持续工作。

## 电脑查看

串口助手选择实际 COM 口、115200、8N1、文本模式。每125 ms轮换输出一个方向，四路约每500 ms各显示一次；策略判断仍在主循环处理新帧时执行，不等待显示周期。

示例格式（非实测数据）：

```text
LASER DIR=LEFT D=320 C=20 STATUS=OPPONENT AGE=3 BAD=0 DROP=0 ERR=0 STATE=HIDING FAULT=NONE
LASER_ESCAPE DIR=LEFT MASK=8 D=320 C=20 FROM=N059 TO=N...
```

`D` 为毫米，`AGE` 为毫秒，`BAD/DROP/ERR` 为累计校验错误/丢字节/串口错误。`MOVING_OFF` 表示移动期间接收已关闭；该状态下显示的距离是历史值，不是当前测量。`MASK` 使用地图北/东/南/西的位0/1/2/3，可同时表达多个威胁方向。

上电默认停车；沿用 KEY2 开始、运行时按键停车的控制。首次测试由用户先验证四路方向与日志、编码器计数，再做实车运动验证；本次未自动烧录或驱动电机。
