# 地图边缘朝外激光屏蔽

日期：2026-10-13。直接接入当前Thief16B四激光工程。仅编译通过，尚未完成硬件验证。

## 屏蔽规则

使用灰度/陀螺/编码器联合定位的逻辑地图XY和车身朝向。地图外围道路中心线为x=0/3300毫米、y=0/2700毫米；3.6×3米物理场地边界在道路中心线外再延伸150毫米。本规则识别的是外围道路，坐标仍为既有地图名义数据，不宣称实测定位精度。

| 所在外围道路 | 屏蔽世界方向 |
|---|---|
| 上沿y=0 | 北N |
| 下沿y=2700 | 南S |
| 左沿x=0 | 西W |
| 右沿x=3300 | 东E |
| 四个角落 | 同时屏蔽两个外侧方向 |

四路方向由车身朝向转换：前0°、左−90°、右+90°、后180°。倒车只是行驶方向反向，不能交换车身前后传感器。例：N005车头朝西时屏蔽右激光（朝北），保留前/左/后；N081车头朝北时屏蔽左激光（朝西）和后激光（朝南）。内部路段仍允许四个方向，再由原道路投影判断是否存在真实连接。无效定位、转弯过渡或XY超出逻辑地图范围时屏蔽全部有效检测。

此处“停用”指软件忽略检测数据：模块供电、发光和UART接收不切换。当前模块只接TX，不能凭这根线关闭电源或发射。无需增加接线、GPIO或串口重新初始化。

## 防止旧数据误触发

- 每次控制和定位更新后、处理激光队列前更新屏蔽掩码。
- 被屏蔽通道直接返回，既不能提供目标威胁，也不能提供“道路清空/目标刚从岔路进入”的证据。
- 屏蔽或恢复时清除对应通道确认窗口和已见标记；同时清除跨通道的入路推断历史，防止旧视角证据继续有效。地图内曾确认的威胁位置记忆保留。
- 恢复后的帧必须严格晚于恢复时刻；同一毫秒内和更早的积压帧均丢弃，支持32位系统时钟回绕。数据进入原5帧/近距2帧滤波重新确认。
- 追踪方向掩码再次排除禁用通道。正常停止日志显示`STATUS=EDGE_OFF D=0 C=0`，不展示外侧历史距离；无效位姿显示`POSE_OFF`。取宝前仍为`WAIT_TREASURE`。

软件检测上限650毫米、经过N005后启用、移动时25毫秒新鲜度与5°朝向筛选、停稳藏点才换线的行为保留。内部道路与场地边界投影仍保留，不能将地图内物体身份识别为警方，也不能保证过滤位于地图内部的人。
