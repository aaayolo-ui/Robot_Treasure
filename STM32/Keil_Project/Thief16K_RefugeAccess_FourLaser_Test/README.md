# Thief16K_RefugeAccess_FourLaser_Test

本工程从当前 `Thief16B_FourLaser_MapStrategy_Test` 独立复制，用于 16K 藏匿点可达方向与接近路线评估实验。

继承 16B 已有源代码：16J 策略、陀螺与灰度联合定位、编码器路段位置估计、四激光接收、650 mm 地图内检测、N005 经过后启动激光、地图边缘屏蔽和 N004↔N006 宝藏区灰度屏蔽。复制没有改变 MCU、时钟、引脚、底盘控制参数或 ST-Link 配置。

`copy_reference.json` 记录复制时191个源文件SHA256。增加纯C藏点结构评分及Flash元数据、107条有界返回环路；路线风险仍优先，环路须通过更严格门槛。默认初始路线和藏点继续N038，N062仍可能因动态排序被选中。八类ARM算法测试226341项通过；117个底层文件及陀螺灰度定位保护逻辑字节保留。

Keil完整编译0 Error(s)、0 Warning(s)，Flash200388B、RAM35392B。当前七场回放与九场完整对照均未改善16J结果，多种替换方法已拒绝；不建议把本实验当成已解决N062问题的升级。100ms实车规划预算保持原值，实际板上耗时未测。
