# 预存地图路线与仿真数据采集工程

复制自本次对话创建的 `Gray12_MapTiming_Log_Test`，保留其前进循迹、轮速控制、制动、JY61P、灰度、电机映射及参数。旧工程及其他试验工程未覆盖。

该工程在 ROM 中保存当前地图的 88 个节点、106 条路段和 21 条前进测试路线。路线表规划覆盖两方向共 212 个 S 路段方向项。每个路口按预设步骤选择直行、左转、右转或停车；直行通过岔路，取消原固定右转优先。N005 位于直道中间，合并计时而非新增灰度路口。

路线与位置算法在 `Algorithm/MapRoute`，名义编码器里程合理性检查在 `User/MapRoutePosition.c/.h`；原应用中接入路线动作和 MT2 日志。`Core/main.c`、CubeMX 外设配置、Control、Hardware、原 PID 参数保留。源码只用于离线准备，不自动烧录或启动实车。

已知起点和起始朝向由用户按 `Tools/MapTimingLogger/map_routes.md` 摆放。默认 R001=N081 朝 N（地图上方）。停止时长按 KEY2 或短按 WK_UP 选择下一路线，KEY1 选择上一条；短按 KEY2 运行。运行中 KEY1/WK_UP/KEY2 停车；停车按键的释放事件会被消费，松手后保持停止且不切换路线，重新按键才执行新操作。正常路线末端停车并输出 `MAP_ROUTE_DONE`；用户再摆下一条起点。本轮不新增倒车或原地 180°掉头。

位置状态由路线序列和可识别路口推进；没有任意起点全局定位或自动重定位。名义里程使用硬件清单的 65 mm 轮胎及原编码器 1560 count/rev，仅用于检查明显过早/过迟的路口。漏检不能保证完全排除，因此实跑前应验证短路线与定位；发现距离、分支、陀螺仪、转后航向或找线异常时制动停车。

USART3 沿用 PB10/PB11、115200、8N1，只需 PB10 接已配对车载蓝牙 RXD，GND 共地，VCC 按用户确认 5 V，蓝牙 TXD 留空。完整接线、采集、参数导出和仿真命令见 [工具说明](../../../Tools/MapTimingLogger/README.md)。不要并接两个模块的 TXD 到 PB11。

MT2 记录 STM32 源时间、R 编号、步骤和两端 N 编号，以及转弯阶段、航向、编码器和丢包计数。分析工具自动对应 S 路段，输出各方向数据与缺口；生成独立仿真配置，原策略默认参数不被合成数据覆盖。源时间单位毫秒不等于物理误差只有毫秒；名义地图距离和轮周需要校准。

工程入口：`MDK-ARM/Gray12_MapRoute_Calibration_Test.uvprojx`。ARMCC 5.06 在修正停车按键释放事件后重新全量构建为 `0 Error(s), 0 Warning(s)`，Code=29900、RO-data=8172、RW-data=288、ZI-data=7424。68 个编译文件及 14 条 Include Paths 无重复，原初始化与 Flash 设置保留；链接图确认地图和路线表进入 Flash。

31 项记录工具测试、107 项仿真测试通过。合成日志另验证 21 条路线的 212 个方向项经过分析和仿真入口，但合成数据不是实测数据，没有写入默认配置或回放。串口未由助手打开，未烧录或驱动电机。**仅编译通过，尚未完成硬件验证**。完整新增/修改文件和差异统计见本目录 `delivery_manifest.json`。
