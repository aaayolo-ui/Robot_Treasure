## 测试流程

1. 上电默认停止。前灰度位于全黑起始线，KEY2 启动；必须成功初始化前后灰度。
2. 正常前进并完成前四个弯；识别第五个已解锁路口后立即制动，不执行第五个弯的转向或继续前进 200 ms。折返点由 `ROUTE_REVERSE_AT_JUNCTION=5U` 设置。
3. 编码器确认四轮停稳后，将车尾作为行驶方向车头，切换倒车。后灰度必须读到普通有效线，否则保持制动并报 `REVERSE_START_REQUIRES_REAR_LINE`；此时全黑不会被当成终点。
4. 物理后灰度负责位置、左右路口、转弯灰度保底；物理前灰度有效时提供双灰度航向纠偏。程序记录前四个已完成转向；倒车时按第4、3、2、1个弯的顺序，各自反向转回（去程左转则返程右转，反之亦然），防止 T 路口右转优先覆盖返程方向。每完成一次返程转向才移除一条记录；重新启动时清空记录。接近、制动、转弯、找线参数不变。
5. 只有四个返程弯全部完成、进入循迹并连续读到三帧普通有效线重新解锁后，才允许物理后灰度 `0xFFF` 触发起始线停车 DONE。返程弯尚未完成时，全黑参与正常路口识别，不直接结束返程；转弯/转后找线中也不判终点。KEY1/WK_UP、运行中短按 KEY2 停车。

地图约定：倒车完成第4、3、2、1个弯后，重新识别正常线，再遇到的全黑横线为起始线。程序根据灰度触发路口，记录的转向只决定左右，不使用编码器累计路程来触发转弯。若漏检/误检路口，或最后一段还有其他全黑横线，仍不能仅凭灰度证明绝对位置。

串口 `RETURN_TURN_DONE REMAINING=3/2/1/0` 表示逐个完成返程转向；`RETURN_FINISH_ARMED WAIT_START_LINE` 表示已允许起点识别；`RETURN_DONE REMAINING=0 REAR_RAW12=FFF` 才表示终点全黑停车。

## 倒车坐标与陀螺仪

倒车时逻辑 FL/FR/RL/RR 对应物理 RR/RL/FR/FL，物理轮速输出为 `(-rr,-rl,-fr,-fl)`。物理后灰度 P12 为行驶方向左侧、P1 为右侧；物理前灰度作尾随时 P1 为左侧、P12 为右侧，沿用逻辑领头/尾随的位置转换。

行驶朝向 YAW = 物理 YAW + 180°并归一化。相对 YAW 差值与左右原地旋转符号不反转，原转弯 PWM 和 50°目标共用。直线仍为灰度控制，未增加原版没有的陀螺仪锁航向。

## 响应优化

- 恢复桌面版 20 ms 控制周期，前后方向统一；不沿用此前工程的 50 ms 周期。
- 倒车全黑安全检查按 5 ms 调度，不等循迹周期。FOLLOW 路口与失线检查也使用 5 ms 调度。
- 同一主循环里的安全检查、路口判断、循迹只读取一次领头灰度并共享结果；下一轮重新采样，切换行驶方向立即作废缓存。
- 同时保留硬件串口中断接收 YAW 和非阻塞调试日志。无新增延时等待。
- 正反向行驶中都暂停阻塞式软件 SPI TFT 绘制，停车、制动等待或故障时更新。因此行驶中屏幕数值停留在上次显示，不是传感器停止采样。
- 5 ms / 20 ms 是软件调度目标，实际最坏响应时间尚未实测；保留原来停稳确认以避免未停车就换向。
