# 新版修改前必读

每次改代码前重读README.md和Docs/修改规范与回归清单.md。用户最新要求优先。
本版从桌面16U RUN8复制，不从MONITOR13继续打补丁。原工程不改。
正常灰度输入、前后板切换、PID/平滑、轮速、转弯和倒车以RUN8为基线，禁止因单个节点增加特例。
位置估计只报告偏差，不得因LOC_DISTANCE/地图航向不符强行制动、微调或禁止灰度巡线。
路线执行仍按真实灰度路口选择规划动作，不能把路线估计冒充绝对定位。
保留用户要求的激光前后1000/左右800mm、五藏点、N011仅东西出口、100RPM/180ms入中心。
当前STABLE5策略保持STABLE4：N038竖停，地图东/西敌车先N021到上方藏点，北敌车走N039-N040。N011北/南/西敌车走11-12-23-31-32-48-49-61-62-63，到63先居中停稳再转90°朝北停（用户已确认），不套旧N012-N013偏好。N063西敌车仍去N078竖停等待新证据；78北敌车走77-76-75再藏，西敌车走63-52到上方藏点。N078非通用第六藏点，无78-87边。侧后方保留可行路线，仅行进前方障碍立即回撤；下一出口须按新落点与道路距离判断，不能只比较方向位。不得恢复周期性反向或中断停车旋转直接出线。
STABLE5仅修改应用交接：普通主转45°后先原地完成相对转角/双板可信线迹确认，80～100°范围连续3次才交原PID；允许一致偏移，不强求居中，不用地图航向±2°锁死。首样本“有线”、外侧001、碎片或1.2秒超时均不能绕过出口确认前进。普通失线恢复也不能凭外侧弱点前推。正常巡线速度、PID参数、180ms入中心及Control文件保持。
巡线优先：双板均无线时不沿地图轴盲行，连续2秒双板无线停车；不得自动烧录、运行电机或占用串口。
源码、构建、离线模型和实车证据分开，编译通过不代表已实测稳定。
