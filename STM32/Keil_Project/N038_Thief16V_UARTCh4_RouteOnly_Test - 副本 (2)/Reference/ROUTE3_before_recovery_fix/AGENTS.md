4. 新回程的MAP_PASS与转弯后缺线阶段不能同速盲冲：紧凑线形交原PID，其余进入原RestartLineSearch；未完成回程转弯时仅后板旧线不能驱动前进，搜索参考用该次转弯相对入口的90度出口。该处理仅在route_trail.returning生效，普通出程动作不变。
5. 回程直行路口记录首次灰度确认时的编码器锚点，通过接线期间轮程继承至下一段，不能晚清零。连续双板无线2秒、真实硬件故障、按键停止仍生效。
6. 回到原藏点后180ms入中心、原停车确认；若入点车身与原藏点轴向垂直，复用原停车90度转动恢复横/竖停。清旧威胁/拦截请求，等待新检测，不因旧证据立即再逃跑。
7. 回程侧后方追车不改变计划。若回程行进前方又出现新的真实障碍，退出本次历史回放并回到原“退至真实路口后重规划”流程，输出TRACE_ABORT_FRONT，不能保留失效回程游标。
