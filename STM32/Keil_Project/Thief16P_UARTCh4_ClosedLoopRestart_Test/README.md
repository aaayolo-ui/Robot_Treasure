# 16P：回撤重启闭环找线

复制自同级 Thief16O_UARTCh4_OdomRestart_Test，原16O保留。

## 变更依据

Documents3.txt 第1330行：N038→N037倒车找线251 mm，RAW=000,040，前侧持续无黑线、后侧仍见线。16O只把后侧见线用于延长距离，未做方向纠偏。16P将重新起步找线改成闭环差速与刹停扫描。

## 当前行为

- 单块灰度仍见有效线：以平均50 RPM行驶，左右差速最多±20 RPM。后侧偏移用于生成最多±4°的目标偏航，使用陀螺仪闭环跟踪；不把后侧误差直接套入正常前侧PID。
- 两块都无有效线：先刹车，连续两次确认轮速停稳，再原地扫描。先朝最近黑线偏向扫描，没找到则扫另一侧，目标为地图道路朝向两侧各4°。无历史偏向时先右后左。每次换旋转方向或由扫描恢复行驶，都先确认停稳。
- 前侧连续3次有效线才恢复正常循迹，以50 RPM作为正常速度平滑器的起始值。后侧见线不会冒充前侧见线，也不会跳过地图节点。
- 扫描和纠偏使用既有TravelFrame一次性转换：倒车时物理后灰度为前侧；逻辑左右差速通过(-RR,-RL,-FR,-FL)变换，原地旋转的物理左右方向不随倒车状态反转。
- 找线仍在LEAVE状态，原有有效激光拦截可优先刹车并接管回撤。仍遵守原有YAW有效性和朝向筛选，扫描目标4°小于激光投影5°容差。
- 无线时不再直退250 mm。闭环行驶仍限制为最多180 mm，且不超过下一节点前50 mm；保留原有4秒起步总时限、堵转及陀螺仪有效性检查。扫描两侧仍找不到线则停车。
- 刹停会关闭速度环，因此扫描/纠偏恢复前明确重新使能速度环，避免只有目标值而车不动。

## 实车诊断

找线期间最多每100 ms输出一行 RESTART_CTRL：T时间、MODE行进模式、PH找线阶段（0纠偏、1刹停、2扫描、3搜索结束）、RAW前后原始灰度、E前后误差、YAW顺时针偏航误差（度×100）、MM编码器距离、LR左右目标RPM×10、BRAKE刹车标记。使用非阻塞整行发送，队列满则丢该条日志。

可根据这些字段分辨：哪块灰度见线、向哪侧修正、轮速目标是否正确、是否在扫描。对失去黑线时的物理横向位置没有绝对测量。
