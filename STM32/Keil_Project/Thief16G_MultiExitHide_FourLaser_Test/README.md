# Thief16G 多出口藏点与停车朝向实验

独立复制自 `Thief16E_VisibilityEscape_FourLaser_Test`，保留硬件、循迹、转向及安全停机模块。仅改藏点/到达朝向评分、拓扑元数据与诊断日志。用户的起步至宝藏前缀保持原样，宝藏处不停。

候选藏点须为真实 T/十字路口，有至少三条通向不同下一有效分岔的活路，并有前后均可通行的停车轴。首次固定 N038；后续根据激光实际检测选择下一藏点。选择目标时保留搜索的路线风险惩罚，并考虑前后换线时间。没有增加不受路线驱动的瞬间停车转向，也没有用警方隐藏全局位置。

回放：[16G](http://127.0.0.1:8765/variants/16g/replay.html)。方向专项有提升，但完整同速比赛复核未优于 16F，因此本工程是独立对照，未推荐为默认替代。说明及准确性边界见 [Docs/15](../../../Docs/15_多出口藏点与等待朝向16G.md)。

本版 Keil ARMCC5 全量编译 0 Error(s), 0 Warning(s)；实际 C 算法 10,802 项检查通过。工作区13,269字节；Flash44,976字节、RAM34,368字节。板上100ms规划时间预算未实测。
