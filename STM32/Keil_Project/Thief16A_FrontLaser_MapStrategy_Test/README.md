# Thief16A 单前激光地图藏匿/逃跑实验

这是从 `Gray12_MapFullRoute_Calibration_Test` 独立复制出的实验工程。原全图标定工程未被修改。

2026-10-10：增加左后轮起步不转的被动诊断，操作见 [STARTUP_DIAG.md](STARTUP_DIAG.md)。这是采集证据的版本，尚未确认或修复该实车故障。

2026-10-11：已增加 [USART2 行驶隔离修正](LASER_DRIVE_ISOLATION.md)。行驶前彻底关闭激光 USART2，藏点停稳后恢复接收，以排除它对 PA2/左后轮 PWM 的影响；实车是否恢复尚待复测。无需改接线。

## 目标

工程把现有 88 节点、106 路段地图烧入 STM32，并让小偷车在只有一只前向 AI-1811 的条件下完成：

1. 从小偷出生点 **N054，车头朝西** 出发；
2. 沿地图穿过宝藏点 N005，不停车、不在 N005 掉头；
3. 到首个藏点 N059 停车；
4. 仅在藏匿状态处理前激光；
5. 距离数据通过地图几何筛选且 5 帧中至少 3 帧成立后，规划到下一个非死路藏点；
6. 逃跑第一段固定选车头反方向的道路，优先利用倒车先手离开来车方向；
7. 到新藏点停车，重复“藏匿—检测—逃跑”。

## 定位方式

2026-10-11 固定取宝路线：N054→N053（右转）→N044（直行）→N036（左转）→N035→N034→N033（右转）→N025→N015→N006（左转）→N005 宝藏→N004。N005 不作为灰度路口，直穿不停；取宝后沿原藏匿流程前往 N059。

执行沿用编码器轮速 PI 闭环、灰度循迹及陀螺仪/灰度转向控制。转弯由路线中预期路口的灰度事件触发，编码器用于路段位置估算与越程保护，不以固定时间替代路口识别。新路线离线检查通过；实车仍需核对节点识别。最新构建记录为 `MDK-ARM/build_fixed_treasure.log`。

坐标原点是 N001，X 向右、Y 向下。地图每个半格为 150 mm，完整车道间距为 300 mm。

运行中位置由“当前路线节点 + 当前路段 + 编码器路程”计算；识别到路口后把位置吸附到对应节点，避免一直累积纯里程误差。TFT 显示当前节点/路段位置、车头方向、正倒车状态和毫米坐标。

N005 是路段内宝藏点，不是灰度路口。规划器只允许沿 N004—N005—N006 直穿，不能在 N005 触发转向或停车。

## 激光过滤

AI-1811 接收：`PA3 / USART2_RX / 115200 / 8N1`。

单点激光不能识别“警察”或“人”的类别，本工程采用地图约束降低误判：

- 只在车辆已停在藏点时触发策略；
- 接受范围 50–600 mm；
- 置信度至少 10；
- 从车辆当前节点沿车头方向投影，必须存在连续合法道路；
- 投影点必须落在 3.6 m × 3.0 m 场地边界内；
- 5 帧滑动窗口中至少 3 帧通过，且有效距离极差不超过 120 mm。

场地坐标边界暂按外圈黑线距边缘 150 mm 推导为：
`X=-150..3450 mm`、`Y=-150..2850 mm`。装车后应实测外圈黑线到场地边缘的距离并修正常量。

由于警戒带距场地边缘 1 m，而触发上限只有 0.6 m，场外队员通常会先被距离门限排除；即使在边缘方向，投影到场外也会被拒绝。单前激光仍无法解决同一路径内非车辆物体的类别识别。

## TFT

128×128 TFT 显示：

- 策略状态：READY / TO_HIDE / HIDING / ESCAPING / FAULT；
- 底盘动作状态；
- 当前节点、车头方向、FWD/REV；
- X/Y 坐标（mm）；
- 激光距离、置信度、5 帧窗口有效数；
- 激光判断原因和当前目标藏点。

## 操作

1. 小车放在 N054，车头朝西，确认轮子悬空或电机电源受控。
2. 上电后电机保持停止。
3. TFT/串口确认初始规划有效。
4. 短按 KEY2 启动“取宝—藏匿”路线。
5. 运行中按 KEY1、WK_UP 或 KEY2 会立即制动并进入故障停止。
6. 到藏点后无需按键；符合地图约束的稳定激光目标会自动触发下一次逃跑。

## 关键模块

- `Algorithm/ThiefStrategy/ThiefMapPlanner.*`：Dijkstra 路线规划、藏点选择和地图坐标。
- `Algorithm/ThiefStrategy/FrontLaserGate.*`：距离、场界、道路投影与稳定帧过滤。
- `Hardware/LaserRx.*`：AI-1811 八字节协议接收。
- `Hardware/UartRxDispatcher.c`：统一分发 USART2 激光与 UART5 JY61P 回调。
- `User/App_ThiefStrategy.*`：底盘状态机与策略衔接。
- `User/ThiefTftPage.*`：策略、坐标和激光信息显示。

## 验证状态

ARM Compiler 6 已对新增和修改的 C 文件完成语法检查。运行时地图脚本验证了初始路线会一次直穿 N005，并连续生成多轮非端点藏匿路线。

ARMCC5 V5.06 update 5 build 528 全量构建通过：0 Error(s), 0 Warning(s)，已生成包含 USART2 隔离的 HEX。最新构建记录为 `MDK-ARM/build_fixed_treasure.log`。该版本起步串口标记为 `START_OK STATE=LEAVE LASER_USART2=OFF`。

到藏点先制动并确认轮速停稳，才启用检测；800 ms 内未停稳则进入故障。运行、停稳和藏匿期间停止键均禁止自动逃跑。

首藏点固定为 N059，后续路线采用距离与反向首段约束的启发式选择，尚未实现完整警方轨迹预测或全局最优路线。激光逃跑决策仅在藏匿时启用，侧后方没有测距覆盖。

TFT 只在停车或底盘允许暂停时刷新，避免软件 SPI 阻塞循迹；行驶时显示可能保留上一帧。内部坐标由节点与编码器估算，尚待实地校准安装偏移和场界。

仅编译通过，尚未完成硬件验证。
