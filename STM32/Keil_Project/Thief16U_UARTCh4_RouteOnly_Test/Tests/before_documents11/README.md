# 16U：700 mm 单帧快速避障与节点换线

本工程从已验证的 16T 独立复制，针对 Documents10 中“倒车后停止、不换线路”和“避障触发不及时”进行最小修改；16T 原工程未改动。

## 日志结论

Documents10 中 N038 出发时多次在 `MM=0` 被新激光帧打断；后续 N004 的真实倒车已经回到节点并重新规划，经 N003、N002 继续行驶。最后一次停止是独立的 `FRONT_NO_LINE` 灰度丢线故障，不是倒车后未规划。因此本版不削弱灰度安全检查，只修正激光触发速度和拦截后的换线策略。

## 修改

- 四路激光触发中心距离由 600 mm 增加到 700 mm；各传感器安装偏移换算保持不变。
- 当前帧同时满足距离、置信度、地图道路投影、场地边界和时效检查时，单帧立即触发，不再等待第二帧。
- 前方或左右侧出现威胁时立即制动，确认停车后沿原路倒回最近的已确认节点，再重新规划并启动。
- 仅后方出现威胁时不倒向后车，而是继续远离，在下一确认节点停车并重新规划。
- 保留 350 ms 反向冷却，避免连续帧造成方向来回切换；冷却期间仍会在下一节点换线。
- 固件标识更新为 `UARTCH4_16U_RUN1` / `ALGO=16U`。
