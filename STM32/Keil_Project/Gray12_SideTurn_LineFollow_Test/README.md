# 12 路灰度最外侧双黑转弯循迹试验

本工程独立复制 `Route15B_SmoothFollow_Test`，复用现有 NCHD12 I2C、前后灰度位置、四轮独立速度 PI、循迹 PID 与平顺控制。来自提供的 `TRACE.c`、`TracePid.c`、`LineFollow.c` 的可用思路是二值加权位置、状态驱动的循迹 PD、偏差降速、基准速度斜坡和转向变化率限制；原文件按 6 路 GPIO 和另一套电机接口编写，本工程按现有 12 路硬件接口实现这些逻辑。

## 操作与转弯

- 前灰度 P12 在车左、P1 在车右；后灰度 P1 在车左、P12 在车右。转弯标志只看前灰度。黑色为 1。
- KEY2 仅在前灰度 12 路全黑 `0xFFF` 时起步。离开黑区的目标速度从约 20 RPM 逐步升至 30 RPM；看到普通有效线后直接进入循迹，不重启四轮速度环。4 秒还未离开则停车报错。
- 循迹中，仅当前灰度最左侧 P11 **与** P12 同时识别黑线时左转，或最右侧 P1、P2 同时识别黑线时右转。两侧同时满足以及 12 路全黑时，右转优先。触发后先停车 100 ms，记录 JY61P 当前 YAW，再按当前 50 RPM 目标原地转向；转向期间不运行灰度循迹 PID，也不使用灰度结束转向。当相对起转 YAW 的绝对变化达到 90.00° 时停止转向、立刻恢复前灰度循迹；后灰度连续有效后恢复双灰度循迹。YAW 数据超过 150 ms 未更新、或 4 秒仍未完成转向，均停车报错。
- 其余有黑线的范围继续用灰度 PID：线在 P5 或 P8 时，将灰度 PID 的最终差速修正提高到 200%；线触及侧面 P1～P4 或 P9～P12、但未满足最外侧双黑转弯条件时，也用 200%；其余中心位置用 100%。前灰度位置偏差始终进入位置 PID，后灰度有效时只额外形成前后差的航向修正，不再平均抵消前灰度 P5/P8 偏差。四轮速度 PI 不变。原先“4 路黑线先降到 40 RPM 的路口接近状态”已移除。
- 停转并切回循迹的同一帧就读取后灰度；后灰度有效则立即启用前、后双灰度位置和航向 PID，不再等待 3 帧。后灰度暂时无效时先以前灰度循迹，后续有效后再切入双灰度，避免无效读数控制电机。
- 两次转弯之间要求至少 3 帧有效循迹线，以免同一黑区重复触发。转弯最长 4 秒；运行最长 60 秒。KEY1、WK_UP 或运行中 KEY2 停车；I2C 错误、无黑线、无法确认的宽黑线、堵转均停车。
- JY61P 使用 UART5：PC12 接模块 RX、PD2 接模块 TX，默认 9600 8N1。转向使用相对 YAW，因此可跨越 YAW 的 ±180° 边界；最终目标角仍须由实车惯性测试确认。

## 调参位置

| 文件 | 参数 | 控制对象 |
|---|---|---|
| `Control/LineFollowPID.h` | `KP/KI/KD` | 前灰度位置误差；后灰度不会抵消前灰度 P5/P8 的偏差 |
| `Control/LineFollowPID.h` | `KH` | 前后灰度误差之差，即双灰度航向修正 |
| `Algorithm/SpeedPI/WheelSpeedPi.h` | `WHEEL_FL_B_*` | B 电机，左前轮速度 PI |
| 同上 | `WHEEL_FR_A_*` | A 电机，右前轮速度 PI |
| 同上 | `WHEEL_RL_D_*` | D 电机，左后轮速度 PI |
| 同上 | `WHEEL_RR_C_*` | C 电机，右后轮速度 PI |
| `Control/FollowSmoothing.c` | `SMOOTH_*` | 循迹基准速度斜坡、弯道降速和差速变化率 |
| `User/App_LineFollowExperiment.c` | `ROUTE_*` | 起步、原地转弯速度与超时、最外侧两路转弯掩码、JY61P 90° 目标及数据超时；中心/侧面灰度 PID 修正倍率和转弯后起步目标 |

灰度控制不是每块灰度各一套 PID：前灰度始终负责位置误差；后灰度有效时，前后之差负责航向修正。四轮速度 PI 则各有独立状态和独立增益入口。轮速 PI 与 PWM 上限沿用已验证基线；当前高速循迹值和新的停转判定仍需实机确认。

## 当前参数与测试边界

| 设置 | 当前值 | 修改位置 |
|---|---:|---|
| 起步直行目标 | 30 RPM | `ROUTE_LEAVE_START_RPM_X10=300` |
| 起步初值/斜坡 | 20 RPM 起，每 50 ms 加约 1 RPM | `ROUTE_LEAVE_INITIAL_RPM_X10=200` / `ROUTE_LEAVE_RAMP_STEP_RPM_X10=10` |
| 循迹直线基准 | 100 RPM | `LINE_FOLLOW_PID_BASE_RPM_X10=1000` |
| 大偏差时最低循迹基准 | 50 RPM | `SMOOTH_CURVE_MIN_BASE_X10=500` |
| 中心边缘/普通中心/侧面修正倍率 | 200% / 100% / 200% | `ROUTE_PID_*_GAIN_PCT`，只放缩灰度 PID 差速输出 |
| 转弯后循迹初值 | 30 RPM | `ROUTE_AFTER_TURN_START_RPM_X10=300` |
| 原地转弯目标 | 50 RPM | `ROUTE_TURN_RPM_X10=500` |
| JY61P 转向目标 | 90.00° | `ROUTE_TURN_TARGET_YAW_X100=9000`；实测过冲可下调 |
| 灰度外环 Kp/Ki/Kd/Kh | 0.025 / 0 / 0.002 / 0.005 | `Control/LineFollowPID.h`，系数按 x1000 写入 |
| 差速修正每 50 ms 最大变化 | 8 RPM（原为 2 RPM） | `Control/FollowSmoothing.c` 中 `SMOOTH_STEER_STEP_RPM_X10=80` |
| B/A/D/C 四轮速度 PI Kp/Ki | 各 0.80 / 0.25 | `Algorithm/SpeedPI/WheelSpeedPi.h`，系数按 x100 写入 |
| 速度 PI 的 PWM 上限 | 300 | `WHEEL_SPEED_PI_PWM_MAX`；硬件定时器周期为 999 |
| 起步/运行 PWM 下限 | 100 / 50 | `WHEEL_SPEED_PI_PWM_START_MIN` / `WHEEL_SPEED_PI_PWM_RUNNING_MIN` |

这里的 PWM 是四轮 PI 每个控制周期计算的输出，不是固定给电机的 PWM。起步 PWM 下限已恢复为 100，且起步/运行下限之后再次限幅，任何配置都不能越过本工程的 PI PWM 上限 300。串口会输出转弯和前灰度故障状态；若高速时依然直接停车，先记录 `FRONT_REJECT` 或 `ROUTE_FAULT` 行。上述数值不代表整车已完成调参。
