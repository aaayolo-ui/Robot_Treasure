# 四路激光有效检测距离调整

日期：2026-10-18  
目标工程：`Thief16B_UARTCh4_MapStrategy_Test`

四路激光共用的软件有效距离上限由650 mm调整为800 mm。对每一路而言，超过800 mm的读数仍保留为传感器数据，但不会被地图威胁门控作为有效障碍证据；地图道路投影、置信度、连续帧稳定性、场地边界屏蔽和宝藏后启用条件均保持原样。

用户提供的现场对应关系为：一格约300 mm，三格约900 mm。软件在800 mm触发，相比该距离提前约100 mm，为避障留出余量。800 mm是策略接受阈值，不代表修改了传感器量程或把900 mm读数改写成800 mm。

当前配置位置：`Algorithm/ThiefStrategy/ThiefStrategyConfig.h` 中 `THIEF_LASER_MAX_MM`。启动串口提示也应显示 `RANGE_MM=800`。

验证状态：源码和启动日志标注已更新；本次未编译、未烧录，也未做新阈值下的实车避障验证。
