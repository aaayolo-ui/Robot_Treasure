# ROUTE7：追赶时连续通过原藏点

用户场景：N052转向N063，警察在N035到N036路上，转弯时激光已经看到，但旧流程先在N063停车，然后才重新触发逃跑。本版让这次可靠观测服务于到点前的路线延长。

## 每次修改前必读及回归

1. 先读本工程 README.md、AGENTS.md、Docs/修改规范与回归清单.md。巡线优先，不允许为追赶跳过灰度路口确认、提前提交节点、半截取消转弯或朝无道路方向冲出去。
2. 旋转时物理探头方向随车身改变。按当前YAW、已校准符号与起始地图航向投影；不能使用进弯前车头的固定东南西北。倒车不能重复交换探头/轮子映射。
3. UART回调只采集证据，不格式化追赶日志、不运行规划、不改变正在旋转的状态。拼接在旋转及接线结束后的正常FOLLOW/LEAVE_START周期执行；原前方障碍反应先执行。
4. 直行通过原藏点使用原MAP_PASS和实际灰度确认。改变目标不代表已经到达原藏点。若延长路线需要转弯，仍执行正常入弯/转弯动作，不承诺全程不停制动。
5. 回撤历史不能在通过原home后继续使用已耗尽的return_left；重新记录从旧home起实际完成的边，不能保存尚未行驶的规划边。本版新增此衔接，未修改历史模块。
6. 对照SL1快照，保持正常PID、平滑、速度、45度主旋转后接线、180ms入路口、短折返恢复、真实停稳刷新、2秒双板无线和KEY停车。PA3声光不能因电机或策略状态被关闭。

## 当前判据和边界

- 只在当前目标前的最后两段收集和使用追赶证据；不改初始取宝流程。
- 帧新鲜度沿用25ms，YAW需有效且年龄不超过50ms，方向符号已知。模型依赖当前路线位置和地图航向基准；不是新增绝对定位。
- 每个物理通道独立连续确认：至少3帧、跨度至少30ms、间隔不超过100ms，投影位置变化不超过120mm。重复帧间隔不足10ms不累计。
- 量程沿用SL1：前后原始值50到1000mm、左右50到900mm，置信度至少20；中心距离仍按原前后+150mm、左右+100mm换算。
- 投影落在地图0到3300mm、0到2700mm内，距真实道路不超过100mm，而且在计划最终行进方向后方至少100mm。不能把场外墙或地图空白视为追车。
- 距原藏点后方至少275mm、证据年龄不超过1500ms时，按地图目标相对方位调用原PlanEscape，再拼接路线；并非激光一报值就无条件跳过藏点。
- 每个原目标最多尝试规划一次。未确认、过期、无可用规划或48步容量/历史容量不足，保留原躲藏计划。本版不会靠盲行弥补这些情况。
- 一旦成功延长不因短时看不到追车恢复旧STOP，避免左右徘徊；后面真实行进前方障碍仍保留最高优先级。若新目标也出现新鲜可靠追赶证据，可以再次延长，仍受容量上限约束。
- 算法固定内存、整型三角插值，无动态分配。本轮增加RAM864字节；整机剩余3400字节，3KB栈已计入RAM。已知调用栈920字节不包含所有间接调用/中断叠加，未实测控制周期与栈水位。
