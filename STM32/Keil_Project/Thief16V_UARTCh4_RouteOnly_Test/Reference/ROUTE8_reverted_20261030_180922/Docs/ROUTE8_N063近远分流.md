# N063北侧近远来车策略

## 路线及判据

N052附近来车：N063→N062→N061→N049→N033→N025→N015→N006→N005→N004→N003→N013→N012→N011。N005仍合并在N006→N004内，其他可观察路口全部保留。最后从N012向西进N011横停；N063出发使用原普通转弯流程。

N035到N036道路上的远车保留原N063→N078→N077→N076→N075方向，再由原规划选择最终藏点。N078是途经点。N063西侧来车临时去N078、其他藏点路线、N011锁定、正前方回撤均保持。

N063坐标(2700,1800)mm，N052在(2700,1500)mm，N035—N036所在行为y=900mm。中线y=1200：北侧已确认回波x=2700且1200<y<1800时走新路线。中心距离恰好600mm或更远、没有北侧定位证据、证据过期时走原分支。位置取决于测距、安装偏移及目标反射表面，是道路区域估计，尚未完成实车标定。

新增HeadingHit只读指定世界方向250ms内的位置，不额外采集硬件，不增加全局状态；其他方向的新回波不覆盖北侧证据。允许测距投影处于两条道路之间，原Snapshot严格道路匹配函数及其他旧算法保持逐字一致。

量程仍为前后1000mm、左右900mm，前后中心换算+150mm。北侧前/后探头原始150mm投影至N052行，250mm虽投影在两路之间仍为近侧，750mm投影至N035—N036行仍走原计划。质量、连续帧确认及场外过滤继续由原入口负责。

## 证据及实测重点

修改前快照Reference/ROUTE6_SL1_before_n063_near共456项，包含源文件、文档、测试和映像。当前源差异ROUTE8_CHANGESET.patch，最终证据VALIDATION_ROUTE8.json、ROUTE8_FILES.json、build_route8.log。离线入口Tests/run_route8.py，共16组。

专项4096项：4种车身方向×9类条件，真实ARM导航验证全部路线连接、模式、N006左转和N005合并。原激光回调注入150/250/750mm，北/南两种停车方向共6次完整模拟，近侧到N011横停，远侧保持南侧路线到最终藏点。旧SL1同脚本16个近侧预期不符已留证，其他条件逐条对照旧版路线保持。

原型专项曾把无符号读取的int8动作与-1比较、以及在旧版缺少N006途经点时仍索引N006，导致测试夹具错误；已修正并在最终固件重跑全套。最终报告绑定源/测试/映像散列。离线传感器与运动响应为模拟，不代表实车成功。

实车重点：N063竖停时，N052附近放车，应首段向N062，经N061和N006到N011；N035—N036放车，应仍首段去N078。核对实际距离、探头通道和串口路线。仅编译通过，尚未完成硬件验证；未自动烧录或驱动电机。
