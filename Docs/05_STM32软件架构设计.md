# 05 STM32 软件架构设计

## 分层结构

```text
main.c
  ↓
Control 控制层
  ↓
Algorithm 算法层
  ↓
Hardware 硬件层
  ↓
STM32 外设（GPIO / ADC / TIM / PWM 等）
```

## 各层职责

| 层级 | 模块 | 用途 |
|---|---|---|
| User | `main.c` | 初始化入口和主循环调度 |
| Control | `Robot_State` | 管理启动、循迹、寻宝、避让、停止等状态 |
| Control | `Strategy` | 根据状态和传感器结果选择动作 |
| Algorithm | `PID` | 提供基础 PID 计算接口 |
| Algorithm | `Navigation` | 路口、路线和移动方向判断 |
| Hardware | `Motor` | 电机启停、方向与速度接口 |
| Hardware | `GraySensor` | 12 路灰度数据采集接口 |
| Hardware | `Infrared` | 四方向红外数据采集接口 |
| Hardware | `Buzzer_LED` | 蜂鸣器和 LED 控制接口 |

## 调用关系

`main → Robot_State/Strategy → Navigation/PID → Motor`

`main → GraySensor/Infrared → Strategy`

`Strategy → Buzzer_LED`

## 编码约定

- CubeMX 生成的底层初始化代码与用户模块分开维护。
- 硬件引脚和外设句柄在 CubeMX 配置完成后接入。
- 模块优先通过头文件接口调用，避免跨层直接操作变量。
- 当前文件只保留最小接口骨架，后续按测试进度逐步实现。
