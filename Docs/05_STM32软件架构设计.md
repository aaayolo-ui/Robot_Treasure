# 05 STM32 软件架构设计

> 本文只描述软件分层、硬件资源和控制流程，不包含完整程序实现。

## 1. 分层结构

```text
main.c
  ↓
Control 控制层
  ↓
Algorithm 算法层
  ↓
Hardware 硬件层
  ↓
STM32 外设
```

## 2. 各层职责

| 层级 | 模块 | 用途 |
|---|---|---|
| User | `main.c` | 系统初始化和主循环调度 |
| Control | `Robot_State` | 管理循迹、寻宝、声光提示、追击和逃跑状态 |
| Control | `Strategy` | 根据角色、状态及传感器结果选择动作 |
| Algorithm | `PID` | 根据当前启用的灰度数据计算循迹修正量 |
| Algorithm | `Navigation` | 路口识别、路线判断和移动方向决策 |
| Hardware | `Motor` | 管理 `Motor_FL`、`Motor_RL`、`Motor_FR`、`Motor_RR` 四个电机对象和四个编码器反馈对象；适配最终确定的驱动拓扑 |
| Hardware | `GraySensor` | 前后两组 12 路数字灰度数据采集与选择 |
| Hardware | `Infrared` | 前、后、左、右红外数据采集 |
| Hardware | `Buzzer_LED` | 高亮 LED 和有源蜂鸣器控制 |

## 3. 硬件资源规划

| 功能 | 资源需求 | 数量/说明 |
|---|---|---|
| 前灰度 | 数字 GPIO 输入 | 12 路 |
| 后灰度 | 数字 GPIO 输入 | 12 路 |
| 红外 | 数字 GPIO 输入 | 4 路 |
| LED | GPIO 输出 | 1 路 |
| 有源蜂鸣器 | GPIO 输出 | 1 路 |
| 电机驱动控制 | PWM、方向控制或驱动模块所需接口 | 数量和连接方式待电机参数、驱动拓扑及 STM32 资源分配后确定 |
| 四个编码器对象 | 定时器或 GPIO 输入 | 为四个配套编码器电机分别预留反馈对象；信号类型和接口数量待客服确认 |
| 四路速度反馈 | 编码器计数与速度计算 | 分别表示四个电机的实际速度；具体实现待编码器参数确认 |
| 下载调试 | SWD | SWDIO、SWCLK、GND、3.3 V，推荐连接 NRST |

STM32F103RCT6 的处理性能和外设资源满足当前控制需求。最终 GPIO、定时器通道和复用关系需在原理图及 CubeMX 配置阶段统一确认。

## 4. 控制流程

```text
正常循迹
    ↓
进入宝藏区域
    ↓
确认获取宝藏
    ↓
持续声光提示
    ↓
警方追击 / 小偷逃跑
```

| 模式 | 灰度输入 | 控制说明 |
|---|---|---|
| 正常循迹 | 前 12 路灰度 | 作为 PID 主输入，完成前进循迹和路口判断 |
| 特殊模式 | 后 12 路灰度 | 按策略切换，用于后退循迹和逃跑扩展 |

任一时刻只选择一组灰度数据作为 PID 输入。

## 5. 调用关系

```text
main
 ├──→ Robot_State / Strategy
 │        ├──→ Navigation / PID
 │        ├──→ Motor
 │        └──→ Buzzer_LED
 └──→ GraySensor / Infrared
```

## 6. 模块目录对应

| 目录 | 模块 |
|---|---|
| `STM32/Control/Robot_State` | 状态管理 |
| `STM32/Control/Strategy` | 比赛策略 |
| `STM32/Algorithm/PID` | PID 循迹算法 |
| `STM32/Algorithm/Navigation` | 导航与路口判断 |
| `STM32/Hardware/Motor` | 电机驱动接口 |
| `STM32/Hardware/GraySensor` | 前后灰度采集接口 |
| `STM32/Hardware/Infrared` | 四方向红外接口 |
| `STM32/Hardware/Buzzer_LED` | 声光提示接口 |

## 7. 开发约定

`Motor` 硬件层需要支持 `Motor_FL`（左前）、`Motor_RL`（左后）、`Motor_FR`（右前）和 `Motor_RR`（右后）四个电机对象及四个编码器反馈对象。最终采用四路独立驱动还是左右侧组合驱动，需要在电机参数、驱动选型和 STM32 资源分配完成后确定；当前不指定 PWM 引脚、方向引脚或定时器编号。

建议保留可扩展接口：

- `Motor_Init()`
- `Motor_SetSpeed(motor_id, speed)`
- `Motor_SetDirection(motor_id, direction)`
- `Motor_Stop(motor_id)`
- `Encoder_GetCount(motor_id)`
- `Encoder_GetSpeed(motor_id)`

- CubeMX 生成的外设初始化代码与用户模块分开维护。
- GPIO 和定时器分配确认后再接入模块接口。
- 控制层不直接操作 STM32 寄存器或外设句柄。
- 先完成单模块测试，再接入状态机和比赛策略。
