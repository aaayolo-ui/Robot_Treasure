# 16K 藏点结构与安全退路实验

2026-10-14。本次针对 N062 靠近中央巡查直道、第三条出口转弯较多，以及 N038 多出口的反馈，独立复制当前 16B，增加结构评价和受限返回路线。16B、16J 及其历史回放保持不变。

**本轮没有证明策略效果提高，也没有消除回放中对 N062 的选择。** 保留版只在动态安全程度接近时使用结构评价，不把更差的替代路线包装成改进。当前主线仍可继续使用原 16J；16K 用于查看评分和后续实验。

| 不同有效分岔出口 | 4 | 3 |
| 2000ms 内、至多一次强制拐弯的出口 | 4 | 2 |
| 北 | N021，600mm，971ms，无拐弯 | 无 |

| 南 | N056，600mm，971ms，无拐弯 | 经 N071、N072 到 N077，900mm，2954ms，两次拐弯 |

出口时间来自现有名义速度、启动与转向参数，不是新测量。N038 的四个方向都能很快到有效分岔；N062 的三出口数量掩盖了南侧两次拐弯和西侧直接暴露的弱点。N062 及其道路仍可通行。

## 结构评价算法

离线枚举连通的最大同向直道，按“长度 × 原地图三路及以上节点数量”选出主要巡查干道。本图选出 N006→N015→N025→N033→N049→N061→N070→N076→N085，2700mm、9 个岔路节点。外围左侧长直道的得分较低，因此没有把“靠近任意长直道”都视作同等风险。

从主要干道每个节点、沿干道两个初始朝向出发，做带车头方向、前进/倒车模式及转向时间的最短路搜索。探测位置采用原节点和路段中点；只允许地图中实际相连的轴向光束，不能越过断开的道路。结果是离散的结构先验，不是连续空间中的精确首次探测时间，更不是实际警方的位置或未来路线。

至少三个不同快速出口，且巡查绕行先验覆盖 340ms 反应预算时，结构等级为 1。原候选 N011、N012、N038、N062 分别得到 (等级/快速出口/先验ms)：(1/4/2241)、(1/3/2641)、(1/4/4481)、(0/2/0)。运行时只读取 Flash 小表，不在 STM32 上重复生成这些数据。

## 保留版如何选路

继续优先考虑六种追击假设下完整转移都通过的路线；不安全路线仍使用 16J 最早接触时间分档、通过假设数及停车轴直行余地的排序。

对于正的终点脱身余量，只有位于同一 120ms 时间带时，结构等级才参与比较；较大的时间带仍优先。同等级继续比较原动态余量。后备搜索仅在原质量分相同时使用等级。结构等级不能越过道路、已观测来车方向及转移风险约束。它也没有证明等级 1 在实际比赛必然更安全。

在原 579 条节点不重复路线之外，增加 107 条完整返回环路（N011 34 条、N012 26 条、N038 47 条），共 686 条，最大每起点/车头候选仍为 67。原路线内容及相对顺序保留。每条环路至少四条边、600mm、两个其他有效岔路，内部节点不重复，没有直接折返，最多 18 秒、28 个节点，并以合法停车轴结束。

运行时进一步收紧：仅开放快速出口至少四个、巡查绕行先验最大的藏点的返回环路；本图为 N038。六种模型必须全部通过该转移及 340ms 准备窗口，且终点余量超过 460ms。只在环路全部执行完后停靠，不会在起点原地来回动。受限环路在本轮正式对照中没有改变最终路线选择。

参数位于新工程 `Algorithm/ThiefStrategy/ThiefStrategyConfig.h`：`THIEF_REFUGE_POLICY=1`、`THIEF_REFUGE_RETURN_CYCLES=1`。关闭两项可复现 16J 的选路行为，36 个实际 ARM C 对照通过。

## 为什么没有强制把 N062 换掉

默认同速第一次转移中，原 N062 路线的终点代理余量约 5907ms；替代 N012 路线约 5874ms，但经过中央干道更多、落点不同。在同一裁判下，直接优先较好等级使持续时间从 180 秒降至 37.224 秒。结构较好并不能证明到它的路线或之后的等待安全。

当前推演只覆盖本次路线及到达后的 340ms 准备窗口，再用到分岔的时间余量估计下一次脱身。它没有完整模拟藏点长时间等待后、再次检测到警方及转弯的全过程；假设中的丢失视野搜索也未覆盖真实对手的任意寻路。这是目前仍选择 N062 的局限。不能通过硬编码禁用 N062 来声称已经解决。

## 被拒绝的试验

| 试验 | 默认同速完整开局 | 默认警方快20% | 处理 |
|---|---:|---:|---|
| 原 16J | 180s 到时限 | 67.321s 被抓 | 保留基准 |
| 无条件等级优先 | 37.224s 被抓 | 33.200s 被抓 | 拒绝 |
| 不收紧的返回环路 | 114.883s 被抓 | 67.321s 被抓 | 收紧门槛；纵向停车对照也曾退步 |
| 第二出口余量直接替代原排序 | 37.224s 被抓 | 33.200s 被抓 | 拒绝 |
| 巡查绕行先验直接加分 | 23.267s 被抓 | 21.301s 被抓 | 拒绝 |
| 当前“警方已转好”假设实现 | 75.949s 被抓 | 25.023s 被抓 | 未保留，不能认定模型已修好 |
| 初始停车轴偏重较长直行余地 | 180s 到时限 | 20.232s 被抓 | 拒绝 |
| 扩展 N020 藏点 | 147.091s 被抓 | 67.321s 被抓 | 拒绝；纵向停车对照180→13.427s |

N020 是严格地图筛选中唯一新增的候选：三个快速出口、南北停车轴，但在外围 1800mm 直道上。离线试验没有证明它更好，未加入正式候选。未编译的“等待到首次检测后再模拟出口”辅助函数提案也没有加入固件；不能用其设想宣称获胜或板上耗时达标。

## 最终对照与验证

全部比较沿用双方有限 600mm 检测、相同警方、运动参数、180秒时限和连续旋转车身接触裁判。没有删掉 N038 同轴近追、N062 强制拐弯或快车来袭的不利对照。原七项场景的持续时间与胜负全部相同。

| 警方速度 | 三个种子16J平均持续 | 三个种子16K平均持续 | N062目标次数，旧/新 |
|---|---:|---:|---:|
| 同速 | 150.939s | 150.939s | 3/3 |
| 快10% | 101.026s | 101.026s | 3/3 |
| 快20% | 67.316s | 67.316s | 3/3 |

九场最终都被抓，不能把持续时间当成获胜概率。N062 次数是规划目标次数，旧报告没有逐次到达节点记录，因此没有伪造旧版的实际 N062 到达数。

ARMCC5 完整 Keil 构建 0 Error(s)、0 Warning(s)，Flash 200388B、RAM 35392B。八类实际 ARM C 测试共 226341 项、0 失败；其中定位 62 条路线、464 次节点确认，包含四种闭合路线方向/陀螺符号组合。剪枝与穷举 36 项决策一致；关闭新功能与 16J 36 项决策一致。117 个底层文件和陀螺灰度定位保护逻辑与 16B 字节相同。

实车继承 16B 的 650mm、经过 N005 后启用、行驶接收、地图外向屏蔽及宝藏文字灰度过滤。当前回放理想定位，仅在停靠时向小偷 C 算法提供激光，没有验证上述实车行为。本次没有烧录、操作电机或测量实板规划时间，100ms 规划限时保持原值。
