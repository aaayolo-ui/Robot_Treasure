# STM32 小偷风险策略 16D

新增工程：[Thief16D_RiskAware_FourLaser_Test](../STM32/Keil_Project/Thief16D_RiskAware_FourLaser_Test/README.md)。16A、16B、16C和原电脑仿真保留，不覆盖历史阶段。

无需服务器、虚拟机或在线训练。STM32本机使用固定数组，进行带行进朝向/正倒车状态的时间搜索、最近检测位置的可达区域更新以及交会风险筛选。藏点拓扑先在电脑生成后烧入ROM，单次搜索最多704个状态。

固定取宝路线保留；当前地图初始藏点选N023。取宝后N004→N003→N013→N012→N023，停稳检测，再转移到新的安全藏点。现在按风险、耗时和藏点质量选路，不再将接近1.5米作为主要目标。暴露藏点冷却30秒。

本版沿用已配置的四激光接线和移动期关闭激光的隔离措施；不是行驶中即时避碰版本。警方速度上限、动作时间及交会余量是可调模型参数，需要实车标定；路口定位控制也仍需实测，不能以算法检查替代节点识别验证。完整实现与局限见工程README。

仅编译通过，尚未完成硬件验证。

用户按KEY2启动，未自动烧录或驱动电机，未自动提交或推送。实际编译资源、电脑验证和文件差异见工程VERIFICATION.md、SOURCE_CHANGES.json、SOURCE_DIFF.patch及FILE_MANIFEST.md。
