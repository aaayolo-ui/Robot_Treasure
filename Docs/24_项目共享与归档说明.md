## 获取与打开

```powershell
git clone https://github.com/aaayolo-ui/Robot_Treasure.git
cd Robot_Treasure
```

在 Codex 中打开克隆后的目录；在 Keil 中打开所需工程的 `MDK-ARM/*.uvprojx`。STM32 工程沿用 ARM Compiler 5；项目此前使用 5.06 update 5 build 528。第三方编译器、安装程序和电脑串口驱动不随源码打包，需在接收电脑上配置。COM 号是本机分配值，需按接收电脑实际端口设置。

## 本机查看回放与实时数据

从仓库根目录启动回放服务：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory Tools/TreasurePursuitSimulator
```

打开 `http://127.0.0.1:8765/variants/16l/replay.html` 或 `http://127.0.0.1:8765/variants/16k/replay.html`。这是在接收电脑本机启动服务；文档里的 `127.0.0.1` 地址不会自动连接原电脑。

实时网页按 `Tools/MapTimingLogger/README.md` 配置实际串口、115200 和 HTTP 端口后启动。它只能显示该电脑当前收到的串口数据；没有实车时可先查看静态回放。
