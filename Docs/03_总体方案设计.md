# 03 总体方案设计

## 1. 设计目标

Robot_Treasure 是面向 **2026 江苏省大学生机器人大赛——密室夺宝项目** 的四轮差速机器人。

核心原则：**稳定优先**。

`稳定循迹 > 高速度`

优先保证：

- 黑线循迹稳定；
- 路口判断可靠；
- 宝藏获取成功；
- 支持比赛追击与逃跑对抗。

方案不采用 Jetson、摄像头视觉、YOLO 或 ROS。

## 2. 机器人总体结构

```text
STM32F103RCT6
      ↓
传感器采集
      ↓
算法处理
      ↓
电机控制
      ↓
四轮差速小车运动
```

```text
前/后 12 路灰度 ─┐
四方向红外 ──────┼→ STM32 → 状态判断/导航/PID → BTS7960 → 左右轮组
宝藏检测 ─────────┘      └→ LED + 蜂鸣器

强力永久磁铁 ─────────────────────────────→ 获取铁块宝藏
```

## 3. 已确定方案

| 功能 | 方案 |
|---|---|
| 主控 | STM32F103RCT6 开发板 |
| 移动 | 四轮普通轮差速底盘 |
| 循迹 | 前后双 12 路数字灰度传感器 |
| 对手检测 | 前、后、左、右四方向红外传感器 |
| 宝藏获取 | 强力永久磁铁吸取铁块 |
| 提示 | 高亮 LED + 有源蜂鸣器 |
| 电机 | 4 个 12 V 37GB 金属齿轮减速电机 |
| 电机驱动 | 2 个 BTS7960，分别控制左右两侧电机 |
| 电源 | 3S 11.1 V 锂电池 + 5 V DC-DC 降压 |

## 4. 循迹方案

| 灰度模块 | 用途 | 工作方式 |
|---|---|---|
| 前 12 路灰度 | 正常循迹、路口判断 | 默认作为 PID 主输入 |
| 后 12 路灰度 | 后退循迹、逃跑及策略扩展 | 特殊模式切换使用 |

```text
正常模式 → 前灰度采集 → PID → 左右轮速度控制

特殊模式 → 切换后灰度 → 后退循迹/策略动作
```

前后灰度不同时参与同一个 PID 闭环。

## 5. 动力结构

```text
左侧 BTS7960 → 左前电机 + 左后电机 → 左侧动力
右侧 BTS7960 → 右前电机 + 右后电机 → 右侧动力
```

| 动作 | 左侧轮组 | 右侧轮组 |
|---|---|---|
| 前进 | 正转 | 正转 |
| 后退 | 反转 | 反转 |
| 左转 | 减速或反转 | 加速或正转 |
| 右转 | 加速或正转 | 减速或反转 |

速度设定以循迹稳定和路口判断可靠为准，不以最高车速为目标。

## 6. 任务流程

```text
启动
  ↓
前灰度 PID 循迹
  ↓
路口识别与路线判断
  ↓
进入宝藏区域
  ↓
永久磁铁获取宝藏
  ↓
确认获取并持续声光提示
  ↓
根据角色执行追击或逃跑策略
```

## 7. 待验证事项

| 项目 | 验证内容 |
|---|---|
| 双灰度安装 | 安装高度、前后位置、线束和离地间隙 |
| GPIO 资源 | 24 路灰度及其他数字信号的最终引脚分配 |
| 电机 | 100～200 RPM 范围内的速度和扭矩选择 |
| BTS7960 | 单驱动并联控制同侧两电机的电流和温升 |
| 永久磁铁 | 吸力、对位容差和行驶中防脱落能力 |
| 电源 | 电机干扰、降压能力、续航和共地可靠性 |
| 整车结构 | 比赛尺寸、0.3 m 车道通过性和转弯包络 |
