# 03 总体方案设计

## 1. 设计目标与边界

Robot_Treasure 为四轮差速机器人，核心原则是“稳定优先”。优先保证黑线循迹、路口判断、宝藏获取和故障停车可靠，再逐步提高速度。不采用 Jetson、摄像头、YOLO 或 ROS。

系统由 STM32F103RCT6、R5 四驱机械平台、四个带编码器电机、MD240A 四路驱动、分路供电、双 NCHD12 灰度模块、四向红外、磁铁及声光提示组成。

## 2. 硬件总体架构

```text
前 NCHD12 ─┐                         ┌─ 前/后/左/右红外
后 NCHD12 ─┴─ I²C ── STM32F103RCT6 ──┤
四路 AB 编码器 ───────────────────────┤
                                     └─ 状态机 / 导航 / PID
                                                │
                                  四路 PWM、方向、使能 GPIO
                                                │
                                          MD240A（TB6612FNG）
                                                │
                         Motor_FL / Motor_RL / Motor_FR / Motor_RR
```

四轮通道的机械和控制映射固定如下：通道 1→`Motor_FL`（左前），通道 2→`Motor_RL`（左后），通道 3→`Motor_FR`（右前），通道 4→`Motor_RR`（右后）。四轮差速实现前进、后退及原地/差速转向；禁止同侧两台电机并联到同一通道。

## 3. 底盘与动力方案

| 项目 | 参数 |
|---|---|
| 底盘 | R5 系列铝合金四驱底盘 |
| 底板 | 2 mm 铝合金 |
| 轮胎 | 65 mm 黑色大摩擦力轮胎 |
| 外形尺寸 | 约 190 mm × 198 mm × 72 mm |
| 商品标注重量 | 约 0.97 kg |
| 转向形式 | 四轮差速转向 |
| 电机数量 | 4 个 |
| 电机支架 | 37 电机支架 ×4 |
| 联轴器 | 金属联轴器 ×4 |

套餐包含铝合金底板 ×1、MC520 编码器电机 ×4、65 mm 轮胎 ×4、37 电机支架 ×4、金属联轴器 ×4、XH2.54 双头排线 ×4、XH2.54 单头排线 ×4、安装工具和固定螺丝。商品尺寸及重量须在收货后重新测量。约 0.97 kg 已包含主要机械结构，后续电池、支架和电路板应控制重量与安装高度。

### 3.2 MC520P30_12V 编码器电机 ×4（已购买）

| 参数 | 数值 |
|---|---|
| 型号/类型 | MC520P30_12V；永磁有刷直流减速电机 |
| 额定电压/减速比 | 12 V / 1:30 |
| 空载/额定转速 | 360±20 RPM / 290±20 RPM |
| 额定/堵转电流 | 0.3 A / 3 A |
| 额定/堵转扭矩 | 1.5 kg·cm / 4.5 kg·cm |
| 额定功率 | 约 4 W |
| 编码器 | AB 相正交霍尔；供电 3.3～5 V；磁环 13 线 |
| 商品标注脉冲数 | 1560 / 输出轴一圈 |
| 接口 | XH2.54 6 Pin |
| 输出轴/单个重量 | 直径 6 mm D 型偏心轴 / 约 150 g |

选用原因是它为 R5 原厂配套型号，电机、支架、联轴器、轮胎和线束尺寸均匹配，四台型号一致且自带 AB 相编码器，无须加工底盘，配套驱动的安装也方便。

搭配 65 mm 轮胎，额定理论线速度为 `290 ÷ 60 × π × 0.065 ≈ 0.99 m/s`，空载理论线速度约 `1.23 m/s`。这对稳定循迹偏快，因此不换电机，而通过最大 PWM 限制、加减速斜坡、编码器速度闭环，以及直线/弯道/路口的分级目标速度控制。初期目标速度约 0.3～0.5 m/s，稳定后再提升。

编码器计算为 `13 线 × 30 = 390`，AB 相四倍频后为 `390 × 4 = 1560`。**1560/圈为商品标注值，收到实物后应通过手动旋转输出轴一圈和 STM32 编码器计数实验进行验证。**它不得被写成未经验证的单通道脉冲数。

### 3.3 MD240A 四路驱动板（技术选型已完成）

| 参数 | 数值 |
|---|---|
| 型号/芯片 | MD240A / TB6612FNG |
| 电机通道 | 4 路独立通道 |
| VM 输入 | 6～15 V |
| 单路连续/峰值电流 | 1.2 A / 3.2 A |
| 逻辑控制电压 | 3.3～5 V |
| PWM 范围/推荐值 | 0～100 kHz / 10 kHz |
| 电机接口 | XH2.54 6 Pin |
| 尺寸/重量 | 约 68 mm × 58.7 mm / 约 26 g |
| 保护 | 过流、短路、TVS 防护 |

正常运行时，`1.2 A ÷ 0.3 A = 4`，单通道连续电流有余量；但 3 A 堵转电流已接近 3.2 A 峰值能力。MD240A 因此适合该电机的正常运行，不能容许长期堵转。软件必须具备 PWM 缓启动/缓减速、最大 PWM 限制、禁止高速直接反转、堵转检测、卡死立即停止、故障延时恢复和连续故障停车。初步规则为：PWM 超过阈值而编码器速度连续 100～300 ms 接近零时，停止对应电机并记录故障；最终阈值由实车确定。

## 4. 供电与布线

```text
3S 锂电池（LB326E，12 V 2600 mAh）
    │
    ├── 总开关 ── 保险丝 ── 动力支路 ── MD240A
    │                                      ├── Motor_FL
    │                                      ├── Motor_RL
    │                                      ├── Motor_FR
    │                                      └── Motor_RR
    └── 控制支路 ── 3A 多路 DC-DC
                         ├── 5V → STM32 开发板及 5V 传感器
                         └── 3.3V → 编码器及 3.3V 模块
```

采用 LB326E 12 V 2600 mAh 3S 锂电池、12.6 V 1.5 A 配套充电器和 3 A 多路 DC-DC；它们与底盘/驱动同属配套产品体系，基本适配已确认。到货仍须检查正负极、满电电压、DC-DC 的 3.3 V/5 V 输出、空载和负载发热、电机启动时 STM32 是否复位，以及驱动板与线缆温升。用户不购买万用表，但接入 STM32 前必须借用实验室或组员的万用表测量。

电机绝不能通过 DC-DC 供电；电池直接供给 MD240A VM。MD240A 板载 3.3 V/5 V 不作为整车主要控制电源。全部模块共地，两个稳压模块的输出不得直接并联。动力线与信号线分开走，电机线避免与灰度/编码器线长距离并行。

## 5. 灰度与红外检测

### 5.1 NCHD12 ×2（技术选型已完成）

| 项目 | 信息 |
|---|---|
| 型号/探头 | NCHD12 / 12 路 |
| 扩展芯片 | PCA9555 |
| 灵敏度与结构 | 可调；每路独立指示灯；带遮光结构 |
| 最小适配线宽 | 商品标注约 10 mm |
| 尺寸/探头间距/重量 | 约 118.8 mm × 30 mm / 约 9 mm / 约 16.5 g |

前模块负责前进循迹和主要路口判断，后模块负责后退循迹与逃跑模式。两者可联合判断车身姿态和路口状态，但默认只允许当前运动方向的主模块进入循迹 PID，不能运行两个相互冲突的独立 PID。

两块模块共用一条 I²C 总线，并由 PCA9555 的 A0/A1/A2 焊盘设置不同地址：

```text
STM32 I²C SCL ──┬── 前 NCHD12
                └── 后 NCHD12
STM32 I²C SDA ──┬── 前 NCHD12
                └── 后 NCHD12
```

| 模块 | A2/A1/A0 | 7 位地址 |
|---|---|---:|
| 前 NCHD12 | 0/0/0 | 0x20 |
| 后 NCHD12 | 0/0/1 | 0x21 |

不需要 24 路独立 GPIO、第二组 I²C 或 I²C 多路复用器；仅当实物地址焊盘无法修改时才评估备选方案。

### 5.2 机械布置和红外

前灰度位于前轮轴线前方、后灰度位于后轮轴线后方，均使用可调高度及前后距离的支架。前、后、左、右红外模块负责对手/边界辅助检测，已确认所选模块能识别黑色 ABS 板；最终规格尚未锁定，以下字段保留为到货验收项：

| 红外信息 | 当前记录 |
|---|---|
| 具体型号 | 待最终型号确认 |
| 供电电压 | 待最终型号确认 |
| 输出电平 | 待最终型号确认；必须核对 STM32 3.3 V 输入安全性 |
| 调节范围 / 最佳检测距离 | 待实车标定 |

实车要验证正面距离、侧面角度、环境光、运动目标稳定性及自身 ABS 板误触发。

## 6. 硬件关联与设计约束

1. 290 RPM 电机配 65 mm 轮胎速度偏高，必须依赖编码器闭环、PWM 限制和减速策略；惯性也要求限制电池与板卡安装高度。
2. 堵转电流接近 MD240A 峰值，软件堵转保护不可省略。
3. 3S 电池电压同时匹配 12 V 电机和 MD240A 的 6～15 V VM 输入；DC-DC 将动力与控制分支隔离，降低电机噪声导致 STM32 复位的风险。
4. NCHD12 的 I²C 接口只占 SCL/SDA 两个引脚，为四路编码器、四路 PWM 和方向控制保留了定时器/GPIO。
5. 四个独立编码器支持四轮速度补偿、卡轮识别与闭环，不因基础阶段同侧同速而失去独立输出能力。
6. 电池应靠近底盘几何中心并低位固定；MD240A 靠近电机缩短动力线；DC-DC 靠近电池输入与 STM32 供电区；STM32 放在便于接线与调试的位置。
7. 电路板使用尼龙柱、铜柱或绝缘板，不能直接接触铝合金底板。编码器/I²C 线尽量短，动力线和传感器线分开；ABS 板不得遮挡灰度或红外探头。
