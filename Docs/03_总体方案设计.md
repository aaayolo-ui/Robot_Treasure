# 03 总体方案设计

## 总体结构

```text
STM32 主控
    ↓
传感器采集（12 路灰度 + 四方向红外）
    ↓
算法处理（循迹 PID + 路线判断）
    ↓
电机控制（四轮普通轮差速）
```

宝藏区域辅助流程：

`进入宝藏区域 → 延时 → 磁铁吸取 → 高亮 LED + 蜂鸣器提示`

## 已确定方案

| 功能 | 方案 |
|---|---|
| 移动 | 四轮普通轮差速底盘 |
| 主控 | STM32 |
| 循迹 | 12 路灰度传感器 |
| 敌方检测 | 前、后、左、右四方向红外传感器 |
| 宝藏获取 | 强力磁铁吸取铁片 |
| 提示 | 高亮 LED + 蜂鸣器 |

## 模块关系

```text
灰度传感器 ─┐
红外传感器 ─┼→ STM32 → 导航/状态判断 → 电机驱动 → 左右轮组
             └→ 宝藏任务控制 → 磁铁、LED、蜂鸣器
```

## 待确定事项

- STM32 具体型号与引脚资源。
- 电机、电机驱动与电池型号。
- 磁铁类型及供电控制方式。
- 正式赛道与宝藏规则参数。
