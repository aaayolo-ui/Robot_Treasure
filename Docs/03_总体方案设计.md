# 03 总体方案设计

## 1. 设计目标

Robot_Treasure 是面向 **2026 江苏省大学生机器人大赛——密室夺宝项目** 的四轮差速机器人。

核心原则：**稳定优先**。

`稳定循迹 > 高速度`

优先保证：

- 黑线循迹稳定；
- 路口判断可靠；
- 宝藏获取成功；
- 支持比赛追击与逃跑对抗。

方案不采用 Jetson、摄像头视觉、YOLO 或 ROS。

## 2. 机器人总体结构

```text
STM32F103RCT6
      ↓
传感器采集
      ↓
算法处理
      ↓
电机控制
      ↓
四轮差速小车运动
```

```text
前/后 12 路灰度 ─┐
四方向红外 ──────┼→ STM32 → 状态判断/导航/PID → 待定电机驱动 → 四个电机
宝藏检测 ─────────┘      └→ LED + 蜂鸣器

强力永久磁铁 ─────────────────────────────→ 获取铁块宝藏
```

| 功能 | 方案 |

| 移动 | 已购买 R5 系列铝合金 520 编码器电机四驱底盘（65 mm 黑轮版本），散件待组装 |
| 循迹 | 前后双 12 路数字灰度传感器 |
| 对手检测 | 前、后、左、右四方向红外传感器 |
| 宝藏获取 | 强力永久磁铁吸取铁块 |
| 提示 | 高亮 LED + 有源蜂鸣器 |
| 电机 | R5 底盘配套 520 编码器减速电机 ×4，具体电气参数等待客服确认 |
| 电机驱动 | 待定；在电机参数、控制方式和 STM32 资源确认后选型 |
| 电源 | 3S 锂电池暂作候选；最终动力电池须匹配电机额定电压和驱动输入范围，控制支路保留 DC-DC 降压思路 |

## 4. 循迹方案

| 灰度模块 | 用途 | 工作方式 |
|---|---|---|
| 前 12 路灰度 | 正常循迹、路口判断 | 默认作为 PID 主输入 |
| 后 12 路灰度 | 后退循迹、逃跑及策略扩展 | 特殊模式切换使用 |

```text
正常模式 → 前灰度采集 → PID → 左右轮速度控制

特殊模式 → 切换后灰度 → 后退循迹/策略动作
```

前后灰度不同时参与同一个 PID 闭环。

## 5. 动力结构

四个车轮保留 `Motor_FL`（左前）、`Motor_RL`（左后）、`Motor_FR`（右前）和 `Motor_RR`（右后）逻辑名称，并规划四个编码器反馈对象。最终采用四路独立驱动还是左右侧组合驱动，需要在电机参数、驱动选型和 STM32 资源分配完成后确定。

| 动作 | 左侧轮组 | 右侧轮组 |
|---|---|---|
| 前进 | 正转 | 正转 |
| 后退 | 反转 | 反转 |
| 左转 | 减速或反转 | 加速或正转 |
| 右转 | 加速或正转 | 减速或反转 |

速度设定以循迹稳定和路口判断可靠为准，不以最高车速为目标。

## 6. 底盘与安装规划

R5 底盘是整车机械基础平台。商品图片可确认底板为 2 mm 铝合金、配备 65 mm 黑色大摩擦力轮胎，外形尺寸约 190 mm × 198 mm × 72 mm，商品标注重量约 0.97 kg。尺寸和重量须在收到实物后重新测量确认，不将商品宣传中的承载、速度或性能描述视为已验证事实。

后续仍需设计和安装：

- 前、后 12 路灰度传感器支架，并预留高度、前后距离和角度调节能力；
- 前后黑色 ABS 板支架；
- 前、后、左、右红外传感器支架；
- 强力磁铁固定结构；
- STM32 开发板安装柱；
- 电机驱动模块安装位置；
- 电池固定结构；
- DC-DC 和电源开关安装位置；
- 线缆固定和防拉扯结构。

电路板不得直接贴在铝合金底板上。STM32、驱动板和 DC-DC 等模块必须使用尼龙柱、铜柱或绝缘板隔离，避免焊点或导体接触铝合金底板造成短路。

## 7. 任务流程

```text
启动
  ↓
前灰度 PID 循迹
  ↓
路口识别与路线判断
  ↓
进入宝藏区域
  ↓
永久磁铁获取宝藏
  ↓
确认获取并持续声光提示
  ↓
根据角色执行追击或逃跑策略
```
