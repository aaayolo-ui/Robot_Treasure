# 03 总体方案设计

## 1. 设计目标与边界

Robot_Treasure 为四轮差速机器人，核心原则是“稳定优先”。优先保证黑线循迹、路口判断、宝藏获取和故障停车可靠，再逐步提高速度。不采用 Jetson、摄像头、YOLO 或 ROS。

系统由 STM32F103RCT6、R5 四驱机械平台、四个带编码器电机、MD240A 四路驱动、分路供电、双 NCHD12 灰度模块、待测试验证的四方向 ToF 敌方检测候选方案、普通红外备用模块、磁铁及声光提示组成。

## 2. 硬件总体架构

```text
前 NCHD12 ─┐                         ┌─ 前/后/左/右 ToF（候选）
后 NCHD12 ─┴─ I²C ── STM32F103RCT6 ──┤
四路 AB 编码器 ───────────────────────┤
                                     └─ 状态机 / 导航 / PID
                                                │
                                  四路 PWM、方向、使能 GPIO
                                                │
                                          MD240A（TB6612FNG）
                                                │
                         Motor_FL / Motor_RL / Motor_FR / Motor_RR
```

从 11C 开始，当前车辆以前车尾重新定义为车头；已确认的物理轮位为：MD240A A→`Motor_FR`（右前）、B→`Motor_FL`（左前）、C→`Motor_RR`（右后）、D→`Motor_RL`（左后）。11D-1 已逐通道确认车辆前进的电气方向为 B/A→ELEC_REV、D/C→ELEC_FWD，原始编码器对应的逻辑符号为 B/D=+1、A/C=-1；车辆后退使用相反电气方向。11D-2 已在落地条件下确认四轮独立速度 PI 的前进直行：左侧分组 B+D、右侧分组 A+C，目标最终 80 RPM，四轮最终约 77～79 RPM，整体左右平均转速差约 0.2 RPM，未出现长期 PI 饱和；B 无固定补偿，B 最大 PWM 为 246（上限 300）。该结论仅覆盖新车头下的前进直行，不表示后退、转向或灰度循迹闭环已验证。四轮差速实现前进、后退及原地/差速转向；禁止同侧两台电机并联到同一通道。

| 外形尺寸 | 约 190 mm × 198 mm × 72 mm |
| 商品标注重量 | 约 0.97 kg |
| 转向形式 | 四轮差速转向 |
| 电机数量 | 4 个 |

套餐包含铝合金底板 ×1、MC520 编码器电机 ×4、65 mm 轮胎 ×4、37 电机支架 ×4、金属联轴器 ×4、XH2.54 双头排线 ×4、XH2.54 单头排线 ×4、安装工具和固定螺丝。商品尺寸及重量须在收货后重新测量。约 0.97 kg 已包含主要机械结构，后续电池、支架和电路板应控制重量与安装高度。

### 3.2 MC520P30_12V 编码器电机 ×4（已购买）

| 参数 | 数值 |
|---|---|
| 型号/类型 | MC520P30_12V；永磁有刷直流减速电机 |
| 额定电压/减速比 | 12 V / 1:30 |
| 空载/额定转速 | 360±20 RPM / 290±20 RPM |
| 额定/堵转电流 | 0.3 A / 3 A |
| 额定/堵转扭矩 | 1.5 kg·cm / 4.5 kg·cm |
| 额定功率 | 约 4 W |
| 编码器 | AB 相正交霍尔；供电 3.3～5 V；磁环 13 线 |
| 商品标注脉冲数 | 1560 / 输出轴一圈 |
| 接口 | XH2.54 6 Pin |
| 输出轴/单个重量 | 直径 6 mm D 型偏心轴 / 约 150 g |

选用原因是它为 R5 原厂配套型号，电机、支架、联轴器、轮胎和线束尺寸均匹配，四台型号一致且自带 AB 相编码器，无须加工底盘，配套驱动的安装也方便。

搭配 65 mm 轮胎，额定理论线速度为 `290 ÷ 60 × π × 0.065 ≈ 0.99 m/s`，空载理论线速度约 `1.23 m/s`。这对稳定循迹偏快，因此不换电机，而通过最大 PWM 限制、加减速斜坡、编码器速度闭环，以及直线/弯道/路口的分级目标速度控制。初期目标速度约 0.3～0.5 m/s，稳定后再提升。

编码器计算为 `13 线 × 30 = 390`，AB 相四倍频后为 `390 × 4 = 1560`。**1560/圈为商品标注值，收到实物后应通过手动旋转输出轴一圈和 STM32 编码器计数实验进行验证。**它不得被写成未经验证的单通道脉冲数。

### 3.3 MD240A 四路驱动板（技术选型已完成）

| 参数 | 数值 |
|---|---|
| 型号/芯片 | MD240A / TB6612FNG |
| 电机通道 | 4 路独立通道 |
| VM 输入 | 6～15 V |
| 单路连续/峰值电流 | 1.2 A / 3.2 A |
| 逻辑控制电压 | 3.3～5 V |
| PWM 范围/推荐值 | 0～100 kHz / 10 kHz |
| 电机接口 | XH2.54 6 Pin |
| 尺寸/重量 | 约 68 mm × 58.7 mm / 约 26 g |
| 保护 | 过流、短路、TVS 防护 |

正常运行时，`1.2 A ÷ 0.3 A = 4`，单通道连续电流有余量；但 3 A 堵转电流已接近 3.2 A 峰值能力。MD240A 因此适合该电机的正常运行，不能容许长期堵转。软件必须具备 PWM 缓启动/缓减速、最大 PWM 限制、禁止高速直接反转、堵转检测、卡死立即停止、故障延时恢复和连续故障停车。初步规则为：PWM 超过阈值而编码器速度连续 100～300 ms 接近零时，停止对应电机并记录故障；最终阈值由实车确定。

## 4. 供电与布线

```text
3S 锂电池（LB326E，12 V 2600 mAh）
    │
    ├── 总开关 ── 保险丝 ── 动力支路 ── MD240A
    │                                      ├── Motor_FL
    │                                      ├── Motor_RL
    │                                      ├── Motor_FR
    │                                      └── Motor_RR
    └── 控制支路 ── 3A 多路 DC-DC
                         ├── 5V → STM32 开发板及 5V 传感器
                         └── 3.3V → 编码器及 3.3V 模块
```

采用 LB326E 12 V 2600 mAh 3S 锂电池、12.6 V 1.5 A 配套充电器和 3 A 多路 DC-DC；它们与底盘/驱动同属配套产品体系，基本适配已确认。到货仍须检查正负极、满电电压、DC-DC 的 3.3 V/5 V 输出、空载和负载发热、电机启动时 STM32 是否复位，以及驱动板与线缆温升。用户不购买万用表，但接入 STM32 前必须借用实验室或组员的万用表测量。

电机绝不能通过 DC-DC 供电；电池直接供给 MD240A VM。MD240A 板载 3.3 V/5 V 不作为整车主要控制电源。全部模块共地，两个稳压模块的输出不得直接并联。动力线与信号线分开走，电机线避免与灰度/编码器线长距离并行。

## 5. 灰度与敌方检测

### 5.1 NCHD12 ×2（技术选型已完成）

| 项目 | 信息 |
|---|---|
| 型号/探头 | NCHD12 / 12 路 |
| 扩展芯片 | PCA9555 |
| 灵敏度与结构 | 可调；每路独立指示灯；带遮光结构 |
| 最小适配线宽 | 商品标注约 10 mm |
| 尺寸/探头间距/重量 | 约 118.8 mm × 30 mm / 约 9 mm / 约 16.5 g |

前模块负责前进循迹和主要路口判断，后模块负责后退循迹与逃跑模式。两者可联合判断车身姿态和路口状态，但默认只允许当前运动方向的主模块进入循迹 PID，不能运行两个相互冲突的独立 PID。

两块模块共用一条 I²C 总线，并由 PCA9555 的 A0/A1/A2 焊盘设置不同地址：

```text
STM32 I²C SCL ──┬── 前 NCHD12
                └── 后 NCHD12
STM32 I²C SDA ──┬── 前 NCHD12
                └── 后 NCHD12
```

| 模块 | A2/A1/A0 | 7 位地址 |
|---|---|---:|
| 前 NCHD12 | 0/0/0 | 0x20 |
| 后 NCHD12 | 0/0/1 | 0x21 |

不需要 24 路独立 GPIO、第二组 I²C 或 I²C 多路复用器；仅当实物地址焊盘无法修改时才评估备选方案。

### 5.2 ToF 激光测距候选方案（AI-1811，待测试验证）

当前敌方检测的候选主方案是前、后、左、右四方向 ToF 测距模块。当前已购买 1 个 AI-1811 ToF 激光测距模块用于测试；只有测试结果合格后，才决定是否再购买 3 个同型号模块并扩展到四方向，或采用 ToF 与普通红外混合方案。普通红外模块暂时保留，作为备用和对比测试使用，不再作为最终首选方案。本文不把“四个 ToF 已经确定使用”写成既定事实。

当前购买款式参数如下：

| 参数 | 当前记录 |
|---|---|
| 系列/工作模式 | AI-1811；主动上报模式 |
| 镜头/通信接口 | 带光学透镜；UART |
| 波特率/刷新频率 | 9600，不可调 / 30 Hz，不可调 |
| 测量距离/测量盲区 | 50～4000 mm / 50 mm |
| 标称测量误差/视场角 | ±5 mm / 约 25° |
| 供电电压/UART 信号电平 | 优先使用 3.3 V / 3.3 V |
| 波长 | 940 nm |

四个模块计划分别朝向前、后、左、右，相邻模块中心方向相差约 90°。比赛赛道没有边框和墙壁，因此采用较近的敌方报警阈值时，不需要重点考虑墙壁和边框造成的误检测。单个模块视场角约 25°，正常安装时四个方向一般不会重叠，但该布局不能形成真正的 360° 无死角检测。

初步主要使用较近的敌方检测阈值，发现敌方距离可先按约 300～500 mm 进行测试，最终值须根据小车速度、制动距离和实测结果调整。软件必须设计进入阈值和退出阈值，避免距离在临界值附近反复跳变；例如“距离小于 350 mm 判定发现，距离大于 450 mm 判定离开”只能作为软件设计示例，不是最终固定参数。

### 5.3 ToF 测试要求

购买单个模块的目的就是先验证实际效果，至少需要完成以下测试，当前不预先填写测试结果：

1. 稳定检测比赛使用的黑色 ABS 板；
2. 50 mm、100 mm、200 mm、300 mm、500 mm 和 1000 mm 距离；
3. 目标处于 0°、15°、30° 和 45° 角度；
4. 静止目标、迎面运动和横向运动；
5. 不同环境光条件下的稳定性；
6. 小于 50 mm 盲区时模块返回的数据；
7. 是否出现 0 值、最大值、无效帧或距离跳变；
8. 实际刷新率和通信稳定性；
9. 模块安装高度和俯仰角是否会导致测到地面；
10. 后续多个 ToF 同时工作时是否互相干扰。

### 5.4 AI-1811 与 STM32 连接及资源约束

单模块测试时使用 USB 转 TTL 模块连接电脑串口。USB 转 TTL 只用于模块到货后的电脑串口测试，最终装车时由 AI-1811 直接连接 STM32：

| AI-1811 引脚标识 | STM32 连接 |
|---|---|
| `V` | 3.3 V |
| `G` | GND |
| `T` | UART_RX |
| `R` | UART_TX |

TX 和 RX 必须交叉连接；不要根据连接线颜色判断引脚，必须依据模块上的 `V`、`G`、`R`、`T` 标识接线。AI-1811 为主动上报模式，会连续发送数据。多个模块的发送端不能直接并联到同一个 STM32 串口 RX，否则可能出现数据帧冲突。

最终四模块通信方案暂未确定，不能提前声称四个模块能够直接接入四个独立 UART。制作 STM32F103RCT6 CubeMX 引脚分配表时，仍需验证可用硬件串口数量、UART 引脚复用、调试串口占用、DMA 和中断资源，以及是否需要串口切换、外部多路复用或其他通信方案。

## 6. 硬件关联与设计约束

1. 290 RPM 电机配 65 mm 轮胎速度偏高，必须依赖编码器闭环、PWM 限制和减速策略；惯性也要求限制电池与板卡安装高度。
2. 堵转电流接近 MD240A 峰值，软件堵转保护不可省略。
3. 3S 电池电压同时匹配 12 V 电机和 MD240A 的 6～15 V VM 输入；DC-DC 将动力与控制分支隔离，降低电机噪声导致 STM32 复位的风险。
4. NCHD12 的 I²C 接口只占 SCL/SDA 两个引脚，为四路编码器、四路 PWM 和方向控制保留了定时器/GPIO。
5. 四个独立编码器支持四轮速度补偿、卡轮识别与闭环，不因基础阶段同侧同速而失去独立输出能力。
6. 电池应靠近底盘几何中心并低位固定；MD240A 靠近电机缩短动力线；DC-DC 靠近电池输入与 STM32 供电区；STM32 放在便于接线与调试的位置。
7. 电路板使用尼龙柱、铜柱或绝缘板，不能直接接触铝合金底板。编码器/I²C/UART 线尽量短，动力线和传感器线分开；ABS 板不得遮挡灰度、ToF 镜头或红外探头。

## 7. CubeMX 资源边界

本次不虚构具体引脚。后续必须验证开发板实际引出脚及复用冲突：4 路 PWM、4 个电机的方向/使能 GPIO、4 组 AB 编码器（8 输入）、一组 I²C、候选四方向 ToF 所需的 UART 接收路径、UART 调试、LED、蜂鸣器、SWDIO、SWCLK、可选电池电压 ADC、备用扩展接口，以及 TIM1～TIM4 编码器模式、PWM 定时器、MD240A 实际接口数量。四个 ToF 的最终串口实现方式仍待 CubeMX 验证；普通红外是否作为混合方案的一部分也未定。
