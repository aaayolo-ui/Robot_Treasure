# 04 硬件清单

## 一、文档用途

本文是 Robot_Treasure 项目的分阶段硬件采购技术文档，供首次参加项目的组员进行选型、询价、采购和到货验收。

阅读本阶段内容后，应能够确认：

- 需要采购的主控与传感器名称和数量；
- 采购时应选择的型号与关键参数；
- 各模块与 STM32F103RCT6 的接口方式；
- 每个模块在机器人中的用途；
- 下单前必须向商家确认的事项。

> 本次仅整理主控、下载调试、灰度循迹和四方向红外检测。其他硬件将在后续阶段补充。

## 二、总体设计原则

| 项目 | 设计要求 |
|---|---|
| 参赛项目 | 2026 江苏省大学生机器人大赛——密室夺宝项目 |
| 机器人形式 | 四轮差速小车 |
| 核心原则 | 稳定优先 |
| 主控平台 | STM32F103RCT6 |
| 循迹方式 | 前后双 12 路数字灰度传感器 |
| 对抗检测 | 前、后、左、右四方向红外检测 |

功能优先级：

```text
稳定循迹
    >
路口判断
    >
宝藏获取
    >
比赛策略
    >
最高速度
```

本项目不采用：

- Jetson；
- 摄像头视觉；
- YOLO；
- ROS。

## 六、12 路数字灰度传感器 ×2

| 项目 | 采购技术要求 |
|---|---|
| 名称 | 12 路数字灰度传感器 |
| 数量 | 2 个，车体前后各安装 1 个 |
| 推荐类型 | 12 通道黑白线检测、独立数字输出、带固定孔的灰度循迹模块 |
| 参数要求 | 12 路响应一致；黑白检测稳定；响应速度快；适合比赛黑线；兼容 3.3 V/5 V 系统 |
| STM32 接口方式 | 优先使用 OUT1～OUT12 独立 GPIO 数字输出；每个模块占用 12 路 GPIO 输入，两个模块共需 24 路 GPIO 输入 |
| 使用用途 | 前灰度负责正常前进循迹、PID 控制和路口判断；后灰度负责后退循迹和后期策略扩展 |
| 采购注意事项 | 确认是数字输出而不是仅模拟输出；确认输出电平对 STM32 3.3 V GPIO 安全；确认模块宽度、孔距、推荐安装高度及黑白输出逻辑 |

### 6.1 前后灰度分工

| 安装位置 | 负责功能 | 使用方式 |
|---|---|---|
| 前灰度 | 正常前进循迹、PID 控制、路口判断 | 前进时作为默认 PID 输入源 |
| 后灰度 | 后退循迹、逃跑模式、策略扩展 | 后退或特殊策略时切换为 PID 输入源 |

两个灰度模块不能同时作为两个 PID 控制源：

```text
前进模式 → 读取前灰度 → 计算循迹偏差 → PID

后退模式 → 读取后灰度 → 计算循迹偏差 → PID
```

### 6.2 GPIO 数字输出接口

每个灰度通道输出当前检测到的黑线/白线数字状态：

```text
灰度 OUT1  ─→ STM32 GPIO 输入 1
灰度 OUT2  ─→ STM32 GPIO 输入 2
     ...
灰度 OUT12 ─→ STM32 GPIO 输入 12
```

| 模块 | 数字输出数量 | STM32 GPIO 输入需求 |
|---|---:|---:|
| 前 12 路灰度 | 12 | 12 |
| 后 12 路灰度 | 12 | 12 |
| 合计 | 24 | 24 |

### 6.3 接口选择

| 接口类型 | 采购结论 | 原因 |
|---|---|---|
| GPIO 独立数字输出 | 优先 | 每路直接提供黑/白状态，读取快，程序简单，便于调试 |
| I2C/SPI 数字接口 | 可接受 | 可以减少 GPIO 占用，但必须确认刷新速度、通信协议和资料完整性 |
| 多路模拟输出 | 不推荐 | 两个模块产生 24 路模拟信号，占用大量 ADC 资源，采集和标定复杂 |

### 6.4 购买前向商家确认

- 是否为 12 路独立数字输出；
- OUT1～OUT12 是否能够同时读取；
- 黑线和白线分别输出高电平还是低电平；
- 输出高电平是否对 STM32 的 3.3 V GPIO 安全；
- 模块支持的供电电压范围；
- 传感器间距、模块总宽度和固定孔尺寸；
- 推荐安装高度和可调阈值范围；
- 若使用 I2C/SPI 版本，是否提供完整协议和示例时序。

# 动力系统

本部分用于确定四轮差速小车的动力器件规格。采购顺序必须先确认 37GB 系列电机的实际电流、扭矩和输出轴参数，再确定驱动模块与轮子，避免器件之间不匹配。

## 1. 直流减速电机

| 项目 | 采购技术要求 |
|---|---|
| 名称 | 37GB 系列 12 V 金属齿轮直流减速电机 |
| 数量 | 4 个 |
| 推荐类型 | 37GB 系列、12 V、低速高扭矩、金属齿轮，优先带 AB 相编码器 |
| 推荐采购关键词 | `37GB 12V 金属减速电机 编码器` |
| 参数要求 | 100～200 RPM，优先选择 120～180 RPM；减速比 1:50～1:100；6 mm D 型轴优先 |
| STM32 接口方式 | 电机动力端不直接连接 STM32；由 BTS7960 接收 STM32 的 PWM 和方向信号后驱动。编码器 A/B 相连接 STM32 定时器或 GPIO 输入 |
| 使用用途 | 为左前、左后、右前、右后四个普通轮提供动力，实现前进、后退、差速转向、追击和逃跑 |

### 1.1 电机参数要求

| 参数 | 要求 |
|---|---|
| 类型 | 金属齿轮直流减速电机 |
| 系列 | 37GB |
| 数量 | 4 |
| 工作电压 | 12 V |
| 推荐转速范围 | 100～200 RPM |
| 最佳转速范围 | 120～180 RPM |
| 减速比 | 1:50～1:100 |
| 输出轴 | 6 mm D 型轴优先 |
| 齿轮材质 | 金属 |
| 编码器 | 优先带 AB 相编码器 |
| 四个电机 | 必须同型号、同批次 |

### 1.2 为什么选择该电机

本项目不是速度竞赛。动力选型需要同时满足黑线循迹、路口判断、宝藏获取以及追击/逃跑，选择优先级为：

```text
稳定性
  >
控制性
  >
扭矩
  >
最高速度
```

| 对比项目 | 高速电机 | 低速高扭矩 37GB 系列电机 |
|---|---|---|
| 起步 | 容易突冲，启停不稳定 | 起步稳定，速度变化可控 |
| 黑线循迹 | 容易冲出黑线 | 留给灰度采集和纠偏的时间更充足 |
| 转弯 | 惯性大，路口容易过冲 | 转弯容易控制，定位更稳定 |
| PID 调节 | 参数敏感，调节困难 | 调节范围更宽，更适合稳定循迹 |
| 负载变化 | 速度波动明显 | 高扭矩使负载变化影响较小 |

高速电机的主要风险：

- 容易冲出黑线；
- 转弯惯性大；
- PID 调节困难；
- 启停不稳定。

低速高扭矩方案的优势：

- 起步稳定；
- 转弯容易控制；
- 负载变化影响小；
- 更适合比赛循迹。

### 1.3 购买前必须向商家确认

| 参数 | 原因 |
|---|---|
| 额定电压 | 确认与 12 V 系统匹配 |
| 空载转速 | 确认速度范围 |
| 额定转速 | 确认实际工作状态 |
| 额定电流 | 选择驱动板并估算持续负载 |
| 堵转电流 | 判断最大负载和驱动余量 |
| 额定扭矩 | 判断带载能力 |
| 堵转扭矩 | 判断极限能力和机械风险 |
| 减速比 | 确认速度和扭矩 |
| 输出轴尺寸 | 匹配轮子轴孔和固定方式 |
| 编码器参数 | 方便后期闭环控制和接口分配 |

向商家询价时应要求提供同一工作电压下的完整规格表，并确认转速数据是空载转速还是额定负载转速。

### 1.4 编码器说明

如果预算允许，优先购买带编码器版本。编码器不替代灰度 PID，而是为每侧轮速提供反馈：

```text
灰度传感器 → 灰度 PID → 生成左右目标速度
                         ↓
编码器反馈 → 速度闭环 PID → 修正左右轮实际速度
```

后期加入速度闭环 PID 后，可提高：

- 左右轮速度一致性；
- 直线稳定性；
- 抗电池电压变化能力。

购买编码器版本时必须确认：

| 编码器项目 | 确认内容 |
|---|---|
| 输出形式 | AB 相还是单路输出；优先 AB 相 |
| 每圈脉冲数 | 明确是电机轴脉冲数还是减速后输出轴脉冲数 |
| 输出电平 | 是否对 STM32 3.3 V 输入安全 |
| 供电电压 | 编码器工作电压及允许范围 |
| 接口线序 | 电源、GND、A 相、B 相的颜色与排列 |

### 2.1 轮子参数要求

| 参数 | 要求 |

| 数量 | 4 |

### 2.2 轮径选择说明

轮子直径会同时影响速度、转向稳定性和循迹效果：

| 轮径 | 线速度 | 转向惯性 | 循迹影响 |
|---|---|---|---|
| 过大 | 较高 | 较大 | 更容易冲线，不推荐 |
| 65～75 mm | 适中 | 较易控制 | 推荐作为首选范围 |
| 过小 | 较低 | 较小 | 可能降低离地间隙和通过性 |

轮径越大，在相同电机转速下速度越高、惯性越大，越容易冲出黑线。因此不能为了提高最高速度而选择过大的轮子。

### 2.3 购买前向商家确认

- 实际轮径和轮宽；
- 轴孔是否匹配 6 mm D 型轴；
- 固定方式是顶丝、夹紧轮毂还是直接压配；
- 轮胎是否为防滑橡胶；
- 4 个轮子能否提供同型号、同批次；
- 安装后是否存在明显偏心或摆动。

### 3.3 驱动板选择原则

驱动模块不能只看商家宣传的峰值电流，必须使用电机规格表中的额定电流和堵转电流进行计算。

同侧两个同型号电机的电流估算：

```text
同侧额定电流 = 2 × 单个电机额定电流

同侧最大堵转电流 = 2 × 单个电机堵转电流
```

| 校核项目 | 要求 |
|---|---|
| 正常持续运行 | BTS7960 实际连续电流能力必须高于同侧两个电机的额定电流之和 |
| 启动或短时卡滞 | 模块、端子和供电路径应能承受短时大电流冲击 |
| 极限堵转 | 依据同侧最大堵转电流评估保护措施，不允许长期堵转 |
| 散热 | 连续电流能力必须按实际散热条件核算，并留有余量 |

### 3.4 购买前向商家确认

- 工作电压范围是否包含 12 V；
- 模块在当前散热条件下的连续输出电流；
- 峰值电流允许持续的时间和条件；
- PWM 输入频率范围；
- 是否支持正反转和制动；
- 3.3 V 逻辑高电平能否可靠识别；
- 是否具有过流、过温保护；
- 是否适合同侧两个 37GB 系列电机并联使用。

# 一、电源系统

## 电源总体设计

本项目采用 **单电池供电**。动力系统和控制系统从电池输出端分为两条独立供电支路，避免 STM32 和传感器直接接入电机动力电压。

```text
3S 锂电池
    ↓
  分两路
    ├──→ 动力支路
    │       ↓
    │   电机驱动
    │       ↓
    │   四个直流减速电机
    │
    └──→ 控制支路
            ↓
        DC-DC 降压
            ↓ 5 V
        STM32 开发板
            ↓
        灰度传感器
            ↓
        红外传感器
            ↓
        LED 和蜂鸣器
```

| 支路 | 输入 | 供电对象 | 设计要求 |
|---|---|---|---|
| 动力支路 | 3S 锂电池 | 两块电机驱动及四个直流减速电机 | 使用动力线，满足启动和堵转瞬时电流 |
| 控制支路 | 3S 锂电池经 DC-DC 降压 | STM32、灰度、红外、LED、蜂鸣器 | 稳定输出 5 V，与动力支路分开布线 |

> 两条支路仍需共地：电池负极、驱动板控制地、DC-DC 输出地、STM32 地和传感器地应建立可靠的公共参考地。

## 3S 锂电池

| 项目 | 采购技术要求 |
|---|---|
| 名称 | 3S 锂电池 |
| 数量 | 1 个 |
| 推荐类型 | 标称电压 11.1 V、带平衡充电接口的 3S 锂电池组 |
| 参数要求 | 满电电压 12.6 V；持续和峰值放电能力满足四个电机同时工作；容量满足比赛及调试续航 |
| STM32 接口方式 | 不直接连接 STM32；电池经 DC-DC 降压为 STM32 提供 5 V，负极与 STM32 GND 共地 |
| 使用用途 | 作为整车唯一主电源，同时为动力支路和控制支路提供能量 |
| 采购注意事项 | 不能只看容量；必须按四个电机工作电流和启动峰值电流选择放电能力，并核对接口、尺寸、重量和保护方式 |

### 电池参数要求

| 参数 | 要求 |
|---|---|
| 电池类型 | 锂电池 |
| 串数 | 3S |
| 标称电压 | 11.1 V |
| 满电电压 | 12.6 V |
| 用途 | 整车主电源 |
| 输出能力 | 满足四个电机同时工作 |

### 为什么选择 3S 电池

3S 锂电池的 11.1 V 标称电压接近 12 V 直流减速电机的额定电压，能够与当前动力方案匹配。

| 选择目标 | 作用 |
|---|---|
| 电压接近 12 V | 使电机工作在合理电压范围 |
| 避免电压过低 | 防止动力不足、起步困难和负载下速度下降 |
| 避免电压过高 | 降低电机和驱动模块损坏风险 |

### 电池选择原则

不能只看容量。电池必须同时满足续航和大电流输出需求：

```text
四个电机正常工作电流
          +
启动时的峰值电流
          ↓
确定电池持续放电能力和最大放电电流
```

电池允许的持续输出电流应覆盖四个电机、驱动损耗和控制支路的总电流，并保留余量。启动峰值能力应依据电机堵转电流数据进行校核。

### 购买前向商家确认

| 项目 | 原因 |
|---|---|
| 容量（mAh） | 决定续航时间 |
| 持续放电倍率 | 决定持续输出能力 |
| 最大放电电流 | 决定四个电机同时启动时的供电能力 |
| 接口类型 | 确认能否与整车配电接口可靠连接 |
| 尺寸、重量 | 影响底盘安装位置、重心和结构设计 |
| 是否带保护板 | 提高过流、过放和短路情况下的安全性 |

还应确认是否带 3S 平衡充电接口，并配套使用适合 3S 锂电池的平衡充电器。

# 二、DC-DC 降压模块

| 项目 | 采购技术要求 |
|---|---|
| 名称 | DC-DC 降压模块 |
| 数量 | 1～2 个 |
| 推荐类型 | 支持 3S 锂电池输入、可调或固定输出 5 V 的降压稳压模块 |
| 参数要求 | 输入支持 12.6 V；输出 5 V；建议持续输出能力 3 A 以上；输出纹波低；满足长期工作散热要求 |
| STM32 接口方式 | DC-DC 输出 5 V 接 STM32 开发板 5 V 输入，GND 接 STM32 GND；传感器从控制支路统一取电 |
| 使用用途 | 将 3S 电池电压转换为 STM32 和传感器需要的稳定 5 V 电源 |
| 采购注意事项 | 确认输入范围包含电池满电时的 12.6 V；核对持续输出电流而非瞬时峰值；首次连接 STM32 前必须测量输出电压 |

## DC-DC 参数要求

| 参数 | 要求 |
|---|---|
| 输入电压 | 支持 3S 电池满电电压 12.6 V |
| 输出电压 | 5 V |
| 输出电流 | 建议 3 A 以上 |
| 稳定性 | 输出纹波低 |
| 散热 | 满足持续工作 |

使用 1 个模块时，由该模块统一为 STM32 和传感器供电。预留第 2 个模块可用于后续将高干扰负载与主控、传感器进一步分开，但是否安装应根据整车实测电流和干扰情况决定。

## DC-DC 连接方式

```text
3S 锂电池
    ↓ 11.1 V 标称 / 12.6 V 满电
DC-DC 降压模块
    ↓ 5 V
STM32 开发板
    ↓
灰度、红外及其他控制模块
```

| DC-DC 端子 | 连接对象 | 接线要求 |
|---|---|---|
| IN+ | 电池正极支路 | 接线前确认极性 |
| IN− | 电池负极 | 与整车公共地连接 |
| OUT+ | STM32 开发板 5 V 输入 | 接入前必须确认输出为 5 V |
| OUT− | STM32 GND | 与传感器地、驱动控制地共地 |

## 接入 STM32 前的检查

```text
DC-DC 连接电池
      ↓
暂不连接 STM32
      ↓
使用万用表测量输出
      ↓
调节并稳定在 5 V
      ↓
再次确认正负极
      ↓
连接 STM32
```

- 必须使用万用表确认输出电压；
- 禁止未经测量直接连接主控；
- 输出电压过高可能损坏 STM32 和传感器；
- 调节过程中应防止表笔或工具造成短路。

# 三、电源抗干扰设计

电机属于大电流负载，启停、换向和堵转时可能产生电压波动、电磁干扰及 STM32 异常复位。

| 干扰来源 | 可能现象 | 建议措施 |
|---|---|---|
| 电机换向与电刷噪声 | 灰度或红外信号跳变 | 在电机端增加合适的抑制电容 |
| 驱动支路大电流变化 | 电源电压下跌 | 在驱动板电源端增加滤波电容 |
| STM32 局部供电波动 | 主控复位或运行异常 | 完善 STM32 电源去耦，缩短供电回路 |
| 动力线耦合 | 传感器误判 | 动力线与信号线分开布置 |

建议增加：

- 电机端电容；
- 驱动板电源滤波电容；
- STM32 电源去耦。

布线要求：

```text
动力线走线区域        信号线走线区域
电池/驱动/电机        灰度/红外/编码器/GPIO
       ↓                      ↓
尽量分开布置          远离大电流和快速开关节点
```

- 动力线和信号线分开；
- 电机线与灰度信号线不得长距离平行；
- 必须交叉时尽量采用短距离交叉；
- 去耦和滤波器件应靠近对应模块的电源端安装。
