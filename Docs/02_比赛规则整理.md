# 02 比赛规则整理

> 以赛事组委会发布的 2026 年正式规则为准。以下参数尚未提供，确认后及时填写。

## 设计约束

| 规则项目 | 正式要求 | 对设计的影响 | 状态 |
|---|---|---|---|
| 机器人尺寸 | 待确认 | 决定底盘长、宽、高及机构布局 | 待确认 |
| 赛道尺寸与材质 | 待确认 | 影响速度、轮胎和循迹参数 | 待确认 |
| 黑线宽度与颜色 | 待确认 | 影响灰度传感器间距、阈值和安装高度 | 待确认 |
| 路口形式 | 待确认 | 影响路口识别与导航策略 | 待确认 |
| 宝藏位置与数量 | 待确认 | 影响路线和磁铁机构设计 | 待确认 |
| 宝藏材质与尺寸 | 待确认 | 决定磁铁吸力和安装位置 | 待确认 |
| 获取成功判定 | 待确认 | 决定检测与声光提示时机 | 待确认 |
| 抓捕触发条件 | 待确认 | 影响四方向红外检测逻辑 | 待确认 |
| 抓捕后的处理 | 待确认 | 影响机器人状态机 | 待确认 |
| 比赛时长 | 待确认 | 影响路线、速度和任务优先级 | 待确认 |

## 规则确认流程

`获取正式规则 → 标记关键尺寸 → 确认判罚条件 → 更新硬件与策略 → 赛前复核`
