## 当前基线

台架已使用的供电路径为：3S 锂电池正、负极分别接入 MD240A `VIN/VM`、`GND`；MD240A `VOUT 5V`、`GND` 分别接入 STM32 开发板 `5V`、`GND`；STM32 `5V/GND` 再接第一块 NCHD12 的 `VCC/GND`。四路电机、四路编码器、第一块 NCHD12、CH340 调试串口、ST-Link SWD 与板载按键均已有实际连接或实机验证记录，详见下表文档。

```text
3S 电池 ──> MD240A VIN/VM ──> 四路电机
                 │ VOUT 5V
                 └────────────> STM32 5V ──> NCHD12(0x20)
所有已连接模块 GND ───────────────────────> 共地
```

### 11C/11D 当前车辆坐标与单轮方向基线

- 当前车头为 11C 重新定义后的车头；物理轮位为 FL=B、FR=A、RL=D、RR=C。
- 灰度模块 P12 侧对应 `VEHICLE_LEFT`，P1 侧对应 `VEHICLE_RIGHT`。
- 灰度标签坐标保持 P1 侧为负、P12 侧为正；车辆横向误差使用 `vehicle_error_x100 = -label_position_x100`，即车辆左为负、右为正。
- 11D-1 已实机确认车辆前进方向：B/FL→ELEC_REV、A/FR→ELEC_REV、D/RL→ELEC_FWD、C/RR→ELEC_FWD；车辆后退使用相反电气方向。
- 前进时原始编码器符号对应逻辑符号为 B/D=+1、A/C=-1。11D-2 已实机确认新车头下的前进直行：左侧分组 B+D、右侧分组 A+C，四轮独立速度 PI 在目标最终 80 RPM 下稳定至约 77～79 RPM，整体左右平均转速差约 0.2 RPM，无长期 PI 饱和；后退、转向和循迹闭环仍待独立验证。
- PWM=180/999 的单轮测试下，四路均可连续转动；没有 B 专用固定 PWM 补偿。旧测试工程及其历史阶段记录可能使用旧车头映射，不能直接作为当前轮位控制基线。
- 12A/13A 已实机确认普通红外单路接口为 `VCC→3.3V`、`GND→GND`、`OUT→PB14`；PB14 使用 `GPIO Input`、`GPIO_NOPULL`，低电平表示 `DETECTED`、高电平表示 `CLEAR`。
  13A 已验证连续障碍检测可触发一次“停车约 200 ms→30 RPM 后退约 1 s→自动停车”的基础联动；该引脚仍仅为测试接口，不是最终整车永久分配。
- 2026-10-10已取消前/后/左/右普通红外扩展；PA3恢复为激光接收计划，其余旧红外接口不再预留，实体拆线状态待确认。

## 修改规则

- 新增硬件前先检查 [02_STM32引脚占用总表.md](02_STM32引脚占用总表.md)，不得直接使用已占用引脚。
- 实施软件引脚改动时须同步修改 `.ioc`、源代码驱动和本目录文档；仅规划阶段明确标为计划，不能宣称工程已启用。
- 未完成实机测试的接线只能写入 `03`；完成实机测试后，才能移入 `01`。
- 文档与实物不一致时，停止上电并重新核对；不得凭猜测接线。

## 安全规则

- 所有模块必须共地；禁止带电插拔 I2C、编码器和电源线。
- 当前由 MD240A `VOUT 5V` 给 STM32 供电时，外部 DC-DC 输出不得同时并联到 STM32 `5V`。
- 电池 `VIN/VM` 不得接入 STM32；电机动力电源不得经过 STM32 或外部 5V 降压输出。
- CH340 只接串口信号和 GND 时，不接其 `5V/3.3V` 输出；ST-Link、CH340、MD240A VOUT 与后续 DC-DC 不能同时作为 STM32 供电源。
