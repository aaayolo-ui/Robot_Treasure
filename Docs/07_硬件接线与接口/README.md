# Robot_Treasure 硬件接线与接口

本目录是项目级的实体接线、STM32 引脚占用与扩展规划的唯一维护入口；不属于任何单一测试工程，也不存放硬件驱动代码。当前参考工程为 [`Gray12_I2C_BasicRead_Test`](../../STM32/Keil_Project/Gray12_I2C_BasicRead_Test)，参考提交为 `69af14c`（完成 12 路灰度传感器 I2C 读取与通道映射验证）。

## 当前基线

台架已使用的供电路径为：3S 锂电池正、负极分别接入 MD240A `VIN/VM`、`GND`；MD240A `VOUT 5V`、`GND` 分别接入 STM32 开发板 `5V`、`GND`；STM32 `5V/GND` 再接第一块 NCHD12 的 `VCC/GND`。四路电机、四路编码器、第一块 NCHD12、CH340 调试串口、ST-Link SWD 与板载按键均已有实际连接或实机验证记录，详见下表文档。

```text
3S 电池 ──> MD240A VIN/VM ──> 四路电机
                 │ VOUT 5V
                 └────────────> STM32 5V ──> NCHD12(0x20)
所有已连接模块 GND ───────────────────────> 共地
```

## 状态说明

| 状态 | 定义 |
|---|---|
| 已实机验证 | 已实际接线，并有实机测试或可追溯验证记录。 |
| 已连接但具体参数待确认 | 接线/信号已使用，但电压、极性、针序等参数尚无独立可靠记录。 |
| 仅软件配置 | 当前 `.ioc` 或代码配置了资源，不单独代表实体接线已完成。 |
| 仅后续计划 | 尚未实机接入和验证；只能记录在 `03` 中。 |

## 修改规则

- 新增硬件前先检查 [02_STM32引脚占用总表.md](02_STM32引脚占用总表.md)，不得直接使用已占用引脚。
- 改动引脚时必须同步修改 `.ioc`、源代码驱动和本目录文档。
- 未完成实机测试的接线只能写入 `03`；完成实机测试后，才能移入 `01`。
- 文档与实物不一致时，停止上电并重新核对；不得凭猜测接线。

## 安全规则

- 所有模块必须共地；禁止带电插拔 I2C、编码器和电源线。
- 当前由 MD240A `VOUT 5V` 给 STM32 供电时，外部 DC-DC 输出不得同时并联到 STM32 `5V`。
- 电池 `VIN/VM` 不得接入 STM32；电机动力电源不得经过 STM32 或外部 5V 降压输出。
- CH340 只接串口信号和 GND 时，不接其 `5V/3.3V` 输出；ST-Link、CH340、MD240A VOUT 与后续 DC-DC 不能同时作为 STM32 供电源。
