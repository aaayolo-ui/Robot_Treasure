## 2026-10-17：UART-CH4 V3.6 四激光汇聚候选（用户确认改线，供电待核对）

用户提供资料后已确认供电目标3.3V、主口RX→PB6/TX→PB7，四只激光TX从原MCU引脚移至RX1～RX4。新增独立 [静止通信测试工程](../../STM32/Keil_Project/UARTCh4_FourLaser_Stationary_Test/README.md)，仅编译通过，尚未完成硬件验证；父工程未改。不能直接把本表接线用于原四串口固件。

测量进展（用户口述）：最初M_TX约2V，可能是连续数据的万用表平均值，不能据此认定空闲高电平。按步骤断开四个子口输入及M_TX→PB7后，VCC、M_TX对模块GND均为十几毫伏；用户随后复测：开发板3V3对GND为3.3V；黑笔固定开发板GND时，模块VCC为3.3V、模块GND为0.9mV；无四个子口输入且M_TX未接PB7时，M_TX对模块GND为3.3V。按这组口述直流测量可安排静止主口测试；动态波形及通信尚未验证，之前零电压读数的具体原因未确认。下一步完全断电后只接回M_TX→PB7、保留四根激光TX断开，人工烧录静止工程，暂不按键、不试跑。

**目的与依据。** 已通过一次路线的 `Thief16B_DIN2_PB15_Compare_Test` 保持 DIN2→PB15、前 USART2 关闭。相同 PB15 接线下的前激光恢复对照再次出现用户报告的左后轮不转；日志在启用 USART2 后记录 PA2/D 数字读回异常。新方案让四只激光通过一个独立主串口接收，保持 USART2 关闭，保留 PA2/TIM5_CH3 电机 PWM。它是有针对性的规避方案，尚不能称为修复完成；数字读回不是示波器测量，不能据此宣称已证明芯片内部复用机制。

**成品板协议。** 依据用户提供的 [UART-CH4 V3.6 说明书](../../硬件资料（部分已有）/UART-CH4串口扩展V3.6模块资料集/UART-CH4串口扩展V3.6模块说明书.pdf) 两页内容及截图：

- 1 个主串口 CH0 扩展 4 个子串口 CH1～CH4；每路默认 9600，设置掉电保存。主口波特率必须先匹配。
- 主口发送 `CH1=115200` 等文本命令配置子口；说明书给出 `OK,115200` 应答。主口配置为 `CH0=115200`；命令结束符及改速时应答使用新旧哪一速率未明确，不作为已知事实写入驱动。
- 主口数据带 `1#`～`4#` 通道前缀。第 2 页串口助手截图未勾选 HEX 发送、HEX 显示，演示为文本收发；尚不足以证明所有原始二进制字节、连续帧和四路并发均可无损转发。
- 这是带成品协议的模块，不照搬裸 WK2114 的寄存器/FIFO 协议。目录没有原理图或 STM32 示例源码，不把芯片规格当作成品固件规格。
- 说明书列出的可设波特率最高为 115200；不擅自设置 460800、921600 等未列值。汇聚容量按实际帧率和附加字节计算，不能把四个子口的标称波特率直接视为持续数据量。

**信号分配目标（用户已确认改线；当前按测量步骤暂时断开部分信号）。** 按丝印辨认端子，不按线色或照片方向数针。

| 发送端 | 接收端 | 用途 |
|---|---|---|
| STM32 PB6 / USART1_TX 重映射 | 扩展板 M_RX / 主口 RX | 配置模块及必要的主口发送 |
| 扩展板 M_TX / 主口 TX | STM32 PB7 / USART1_RX 重映射 | 四路汇聚数据 |
| 前激光 T/TX | 扩展板 RX1 | CH1，前向 |
| 左激光 T/TX | 扩展板 RX2 | CH2，左向 |
| 右激光 T/TX | 扩展板 RX3 | CH3，右向 |
| 后激光 T/TX | 扩展板 RX4 | CH4，后向 |

四只激光 R/RX 仍悬空；扩展板 TX1～TX4 暂不接传感器。迁移后四只激光不再直连 PA3/PB7/PC11/PB11，尤其不能让左激光 T 与扩展板 M_TX 同接 PB7。PB6 是旧 TFT_RST 定义，软件已取消 TFT，实体也必须确认已断开屏幕。PB10 蓝牙日志、PC12/PD2 陀螺仪、PB15/DIN2、PB14/E2B 与全部电机/编码器沿用已验证接法。USART1 必须保持 PB6/PB7 重映射，不能恢复到 PA9/PA10。

**供电与电平尚需实物复核。** 模块标注及说明书给出 2.5～5V 供电范围，可选 3.3V 作为本方案供电目标；说明书示例的 VCC=5V 不代表串口必然输出 3.3V。先确认供电能力与 VCC/GND 丝印，测扩展板主口 M_TX 对 GND 的空闲高电平，再决定直连或电平转换。此测量不证明全部收发门限或波形质量；不凭未知 U2 型号声称自带电平转换。激光、MCU 与扩展板需共地；各子口 VCC 不自动接入激光已有电源，避免并联不同供电源。

**实施与验收顺序。**

1. 保留三激光已通过工程，另建扩展板通信测试副本；最初只验证电平和串口，电机不启动。
2. 确认主口实际速率，先配置/验证子口，再设置并复核主口速率。记录实际应答、结束符、掉电记忆和开机提示；不能反复盲发配置命令。
3. 先接 CH1/前激光，只以原始字节日志确认 `AA 05`、8 字节帧及累加校验；验证 00、0D、0A、23、31～34 等字节不会被截断或误当通道标记。通道前缀、分包间隔与有效载荷的界限须有实测依据。
4. 逐路扩至四激光，检查并发通道归属、校验失败、丢帧、更新间隔及汇聚延迟。接收端应有字节预算、溢出/超时恢复；未知通道或损坏帧不能用于决策，过期数据不能因晚到被视为新检测。
5. 通信验证通过后，才在独立小偷工程中接入原过滤/策略接口，保留取宝后参与决策、650mm 门槛、地图外侧屏蔽。正式接收前清理取宝前缓存，防止用陈旧数据触发逃跑。USART2 全程关闭，不能为收前激光再启用它。
6. 静止检查 PWM=0、STBY=0；之后由用户另行人工启动路线，比较 PA2/D、四轮反馈及控制周期。未完成该对照前，不修改 PID、PWM 引脚或定位保护阈值。
