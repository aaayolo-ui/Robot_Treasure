# 四方向激光扩展接线规划

## 已提供的配套固件

独立工程 [Thief16B_FourLaser_MapStrategy_Test](../../STM32/Keil_Project/Thief16B_FourLaser_MapStrategy_Test/README.md) 已按本表实现四路接收、独立过滤、方向换算、逃跑触发、PB14编码器输入以及PB10电脑日志，取消TFT。原16A保留，不能用原16A搭配新接线。ARMCC5全量编译0错误0警告；仅编译通过，尚未完成硬件验证。移动期间沿用原方案暂停检测，停稳藏匿后恢复。最新实现和测试以16B README、VERIFICATION为准。

日期：2026-10-11。用户已确认新增三只为同款 AI-1811，安装在左、右、后；没有串口扩展板。本次只考虑 TX 接收通道，VCC/GND 由用户自行处理。已根据用户提供的绿深系统板原理图及当前源码确定下列改线方案；它尚未接线验证，当前单前激光固件不支持此方案。

## 已确认与待确认

- 现有前向 AI-1811 的 T/TX 接 PA3，用户已反馈接线；小偷工程已有单路解析。

- 本次不修改供电方案。

## 方向与通道计划

| 方向 | 模块 T/TX 连接 | 当前状态 |
|---|---|---|
| 前 | PA3 / USART2_RX，JP1 第11脚 | 现有连接；当前固件移动期间关闭接收 |
| 左 | PB7 / USART1_RX（重映射），JP3 第8脚 | 计划；先断开 TFT，释放 PB7 |
| 右 | PC11 / UART4_RX，JP3 第15脚 | 计划；先移走左前编码器 B 相 |
| 后 | PB11 / USART3_RX，JP1 第19脚 | 计划；先断开日志设备 TX |

## 必须配套的一处迁移与断线

| 信号 | 原接收/输出脚 | 新脚 | 原理图排针 |
|---|---|---|---|
| TFT | PB4～PB9 信号连接 | 不再接入 | 拔掉屏幕/断开屏幕信号线；原 JP2 第4脚连接 PB7 |
| 左前轮 FL/B 编码器 B 相 | PC11 | PB14 / EXTI14 | 新脚 JP1 第26脚 |
| 蓝牙或外置 USB 转 TTL 的 TX | PB11 | 不接，单独绝缘 | PB10 → 日志设备 RX 继续保留 |

若 TFT 直接插在 JP2 上，拔掉屏幕；若通过线连接，断开屏幕信号线。仅在软件不调用屏幕并不能释放 PB7，必须同时解除其物理连接。PB15 不再规划为 TFT CS，暂不分配新用途。

PB14 若仍有旧红外 OUT，先移除。PB14/PB15 在当前小偷源码和 IOC 中未配置使用，在所提供原理图上分别引出到 JP1，未见其他板载负载。全部排针编号以原理图标号为依据，实际连接优先核对板上的 PB7、PC11、PB11、PB14、PB15 丝印，勿从照片朝向推算脚号。

电机 PA10 不改。原理图显示板载 CH340G 的 TXD 直接接 PA10，因此之前提出的 PA10 激光候选撤销：即便移走电机 IN2，PA10 仍连着另一输出，不能直接并接激光 TX。板载 CH340 的 RXD 接 PA9，不等同于外置日志通道 PB10/PB11。

## 为什么不能直接分配三个 GPIO

AI-1811 使用 115200、8N1 主动串口上报，不是普通数字障碍 OUT。USART1 的接收候选 PA10/PB7 分别被电机/TFT 占用；UART4_RX PC11 被编码器占用；USART3_RX PB11 为日志通道；UART5_RX PD2 为陀螺仪；USART2_RX PA3 为前激光。PA10 与 PB7 只是同一 USART1 的不同映射。

释放 PB11 可在保留 PB10 单向日志的条件下增加一路，但仍缺两路，且必须断开 USB 转 TTL/蓝牙的 TX 到 PB11，修改接收处理。不得把两个输出端并接。

## 可选实现方向

本次选用四路硬件 UART 接收，不需要串口扩展板。16B独立工程已配套实现：取消 TFT 初始化、刷新和 PB7 屏幕输出配置；USART1 重映射并仅接收、UART4 仅接收、USART3 保留 PB10 发送并加入后激光接收；四路各自拥有接收缓冲、帧解析、超时和方向标签。将编码器 B 相输入与 EXTI 改到 PB14。

原16A编码器代码一次读取GPIOC后同时解析PC10/PC11；16B已改为分别读取PC10与PB14，并处理EXTI10/EXTI14。

TFT 取消后 PB6 不再规划为屏幕 RST，USART1 只需 PB7 接收。前激光 USART2 的现有移动期关闭逻辑仍需另行评估，本次接线规划不宣称四路可在行驶中连续检测。

电脑日志路径：STM32 PB10（USART3_TX）→车载蓝牙 RX→无线透传→电脑端蓝牙 TX→USB转TTL RX→电脑串口。车载蓝牙 TX 不接 PB11，PB11 专用于后激光。串口日志计划使用 115200、8N1；电脑 COM 号以插入设备后实际枚举为准。16B已实现带DIR方向标签的四路日志；原16A不具备此输出。

## 接入后必须补的验证

- 四路分别校验帧、距离、方向标签和数据更新时间；拔掉一路应只使该方向失效。
- 电脑串口分别显示前/后/左/右距离、数据有效性和更新时间；超时显示无数据，不复用旧距离。
- 检查多激光互扰、目标材质/角度以及电机运行时的电源和串口稳定性。
- 在独立工程核对四轮控制、编码器和陀螺仪未被接收中断或复用配置影响；不自动驱动电机。

16B配套驱动与策略已实现并编译通过，未烧录或进行实车验证。
