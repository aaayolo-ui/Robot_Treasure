# AI-1811 激光接线与恢复计划

更新：2026-10-10。用户取消普通红外探测，改用照片所示板号 `JH-AI-1811-V1.03` 模块。先恢复一只模块，数量及安装方向尚未明确，不将单路接线当作四方向方案。

## 接线

按模块背面的 `V G R T` 丝印逐根核对，断电接线。照片对应红线V、黑线G、黄线R、绿线T；线色只帮助识别本张照片，实际接线以丝印为准，不按观看角度定义左右针序。

| 模块端 | 功能 | 接到哪里 |
|---|---|---|
| V | 电源正 | STM32开发板3.3V |
| G | 电源地 | STM32 GND |
| T | 模块TX，主动输出数据 | PA3 / USART2_RX |
| R | 模块RX，接收配置命令 | 本次不接，末端单独绝缘 |

厂家《使用前必看》推荐统一3.3V供电；TX/RX为3.3V电平。该资料仅对明确的WU型号给出5V供电例外，本计划不依靠该例外，沿用历史已验证的3.3V接法。

PA2是电机D的PWM，不能为了发送激光命令改成USART2_TX。PA3若还有左侧红外OUT接线，先断电移除，不允许两个模块输出并接。PB10/PB11继续用于USB转TTL/蓝牙日志，PC12/PD2继续用于JY61P，不与激光共接。

## 软件和验证边界

- 主动上报使用115200、8数据位、无校验、1停止位，USART2只接收；历史12B源码及IOC均如此配置。
- 历史接收帧为8字节：`AA 05 FW_L FW_H DIST_L DIST_H CONF SUM`，距离小端、单位mm，校验为前7字节和的低8位。资料中的9600询问式Modbus是另一模式，不能混用。
- 当前全图标定工程配置USART3日志和UART5姿态，并没有USART2激光接收。只接线不能让该程序自动输出距离；接入当前整车程序须另建实验工程并复用已验证解析，不能覆盖验证基线。
- 本次只更新文档，没有修改固件、编译、烧录或驱动电机；当前恢复接线和整车通信尚未硬件验证。
- 接线后先在电机不运行条件下验证稳定帧、校验、距离变化和可信度，再做避障联动。激光测距仍不能单独判断目标是脚还是对方车辆。
- 多只主动上报模块不能共接同一RX；其他方向通道须待数量、板上引出和资源约束明确后单独规划。
