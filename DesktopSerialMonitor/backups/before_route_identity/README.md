# 小车串口监控一体助手

桌面新入口：`C:\Users\Administrator\Desktop\小车串口监控一体助手.exe`。

## 使用顺序

1. 点“开启后台”。这一步不会打开串口。本地监控页签随即可用。
2. 选择 COM 和波特率，点“连接串口”。正常配置为 115200 / 8N1，其他参数可在“更多参数”调整。
3. 收到的字节同时进入“串口调试”和“本地监控”，后台只打开一次串口。
4. 连接成功后，如需远程查看，手动点“开启同步”，再切换“公网监控”。
5. 关闭同步只停止上传；关闭后台同时停止同步并释放串口。退出窗口时也可选择全部关闭。

启动一体助手只读取状态，没有注册开机启动、计划任务或系统服务。状态不满足时按钮禁用，并显示操作提示。

## 功能

- COM、波特率、数据位、校验、停止位选择；连接、断开和刷新。
- 文本及 HEX 接收、电脑接收时间戳、暂停显示、清空、保存当前显示文本。
- UTF-8 文本及 HEX 发送、追加 CRLF；定时发送须手动勾选。断开或发送失败自动停止定时发送，不自动重发指令。
- 当前显示保留约 128 KiB，后台提供 512 KiB 追赶缓冲。原始接收字节持续写入本机日志，不受清空或暂停显示影响。
- 内嵌本地和原公网网页；本地副本增加浅色紧凑样式，原始监控文件和已发布的公网网站没有改动。

公网地址仍是 `https://robot-treasure-monitor-1026.nicemug257.chatgpt.site/laser_live.html`。此前的网络访问拦截没有在本任务中解决。公网同步状态只表明本地进程运行，不等于网络上传成功或传感器有效。
