# 小车串口监控一体助手

桌面新入口：`C:\Users\Administrator\Desktop\小车串口监控一体助手.exe`。

## 使用顺序

1. 点“开启后台”。这一步不会打开串口。本地监控页签随即可用。
2. 选择 COM 和波特率，点“连接串口”。正常配置为 115200 / 8N1，其他参数可在“更多参数”调整。
3. 收到的字节同时进入“串口调试”和“本地监控”，后台只打开一次串口。
4. 连接成功后，如需远程查看，手动点“开启同步”，再切换“公网监控”。
5. 关闭同步只停止上传；关闭后台同时停止同步并释放串口。退出窗口时也可选择全部关闭。

启动一体助手只读取状态，没有注册开机启动、计划任务或系统服务。状态不满足时按钮禁用，并显示操作提示。

## 功能

- COM、波特率、数据位、校验、停止位选择；连接、断开和刷新。
- 文本及 HEX 接收、电脑接收时间戳、暂停显示、清空、保存当前显示文本。
- UTF-8 文本及 HEX 发送、追加 CRLF；定时发送须手动勾选。断开或发送失败自动停止定时发送，不自动重发指令。
- 当前显示保留约 128 KiB，后台提供 512 KiB 追赶缓冲。原始接收字节持续写入本机日志，不受清空或暂停显示影响。
- 内嵌本地和原公网网页；本地副本增加浅色紧凑样式，原始监控文件和已发布的公网网站没有改动。

公网地址仍是 `https://robot-treasure-monitor-1026.nicemug257.chatgpt.site/laser_live.html`。此前的网络访问拦截没有在本任务中解决。公网同步状态只表明本地进程运行，不等于网络上传成功或传感器有效。

## RESET 后整轮累计计时（2026-10-29，当前计时规则）

计时范围改为控制板 RESET 至下一次 RESET，包含行驶、停车、故障、纠偏和回撤。路线 START/END、新路线编号、“回到初始位置”及暂停串口显示都不再清零这个整轮计时。旧的按路段/停车计时器仅保留在内部用于识别路线边界，不再用于界面上的三分钟记录。

连接串口后按板上的 RESET，收到 BOOT 后开始；通过主控复位后的毫秒时间补齐初始化延迟。若连接较晚，可根据校验通过的 MT3 时间或 BOOT_STATUS 的 T 时间恢复本轮已过去的时间。尚未收到复位或主控时间时显示“等待 RESET”，不把打开软件的时刻当复位。

时间显示由电脑单调时钟连续累计，停车或暂时没有串口记录仍继续，串口中断会有文字提示。180 秒变色并标注“已满 3 分钟”，之后继续累计；不会发指令让小车停车。再次收到 RESET 启动记录或已确认的主控时间归零时重开一轮。

后台需关闭后重新开启一次，再手动连接串口并按小车 RESET。未升级的后台显示“重开后台后启用 RESET 整轮计时”，不继续展示旧的单段行驶时间。软件和网页依旧不会自动打开串口。

这轮新增 7 项整轮计时检查，覆盖停车/故障/重规划不清零、180 秒阈值、下一次 RESET、晚连接、时间状态恢复及时间回绕；没有驱动车辆实测。原版保存在 `backups/reset_round_timer_20261029/`。

## KEY2 整轮计时（2026-10-29，替代上一节 RESET 起表规则）

此版本仅更改整轮计时，界面与功能保持原样。先连接串口，再按板上的 KEY2 成功起步；收到校验正确、地图签名与道路有效的本轮首次 START 后从 0 秒持续累计。RESET 仅清零并等待下一次 KEY2，上电等待时间不计入。躲藏、停车、故障、重规划、网页复位和同端口重连都不暂停本轮，180 秒后继续累计并提示满 3 分钟。

当前固件没有独立的 KEY2 按下时间戳，起表依据成功起步遥测，包含串口传输延迟；中途才连接无法恢复此前 KEY2 时间，不以主控上电时间代替。内部路段计时保留用于识别路线批次，不影响整轮显示。新一轮建议 RESET 后再 KEY2。

旧版原样备份在 backups/key2_round_20261029。独立新版源代码位于相邻 DesktopSerialMonitorTelemetry，旧版不包含新版的布局改动。更新后需手动重开后台、连接串口，再按 KEY2。

## 手动结束本轮计时（2026-10-30，当前规则）

点击“回到初始位置”或“暂停显示”都会结束本轮并保留已用秒数。“恢复显示”只恢复串口显示，不续表；串口采集与原始日志保持接收。计时下方显示“本轮已结束”。下一次 KEY2 成功启动新一轮时从零起表；已结束的秒数在板上 RESET 等待期间也保留。实车普通停车、躲藏、纠偏与重规划仍继续累计。
