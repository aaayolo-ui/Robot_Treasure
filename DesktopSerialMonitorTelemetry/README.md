# 小车串口监控一体助手 · 车体感知版

独立于定位提示版，手动开启后台、连接串口。没有公网同步入口或公网桥接程序，没有开机自启。原 WHEELTEC 程序未修改。

- 桌面文件：小车串口监控一体助手_车体感知版.exe。
- 本地后台：127.0.0.1:8767；运行目录：%LOCALAPPDATA%/RobotTreasureMonitor/Telemetry-v2。
- 原定位提示版继续使用 8766 与 Integrated-v1，两版互不覆盖文件。不能同时连接同一 COM 口；先断开另一版。
- 先开启后台，再连接串口，然后按 KEY2 开始本轮。RESET 清零并等待 KEY2，停车与重规划继续累计，满 180 秒提示后继续计时。要捕获起点，需要在 KEY2 之前连接。固件无独立按键时间戳，使用校验通过的首次起步遥测，存在传输延迟。
- 地图与车体并排；小窗口上下排列。地图支持拖动、滚轮缩放、右下角调整高度。
- 四个激光读数围绕车体随实际 YAW 移动，数字保持正向。偏航角、航向误差与激光统一为 36px。使用最短角差与 180ms 过渡；过期朝向不继续运动，系统减少动态效果设置有效。
- 朝向遵循陀螺仪原点，收到 LOC 的 CW_SIGN 才能识别旋转方向；没有该字段时提示待上报。不声称已完成绝对地图朝向标定。
- 前后各 12 格：亮格=该位识别黑线，灰格=未识别。前板按 P12 到 P1，后板按 P1 到 P12 排列，与当前工程安装定义一致。旧采样淡化并标注来源/时间，零掩码也正常更新。

## 连续灰度数据的实际限制

固件目前常见 MT3 只包含路口处的单块板处理后灰度，不能恢复连续的前后十二位原始状态。新版同时读取明确包含前后 RAW 对的 MAP_GRAY、RESTART_CTRL、LOCAL_LINE、LOC_CANDIDATE、TURN_EXIT_BOOST。只含一个 RAW 的日志不猜测另一块板。

已支持后续固件上传协议（本次没有修改或烧录固件）：

```text
GRAY_LIVE T=12345 FRONT=07F REAR=8E8
```

FRONT/REAR 为 0..FFF 的十二位十六进制原始掩码，T 为主控毫秒。收到新数据才更新，1500ms 后标旧采样。不要仅调高网页轮询就宣称传感器采样率提高。航向误差当前取 LOC 停靠记录，也可能是旧数据；有值不等于连续实时上传。

## 验证

运行 build.ps1 生成 EXE，资源不包含串口日志、console.key 或公网凭据。Python 离线测试覆盖串口共享、批次、计时、定位不确定与灰度解析；test_telemetry_view.js 使用实际 HTML 渲染函数检查角度跨零、四路位置、24 位灯条和过期状态。桌面界面只进行了未连接串口的显示与手动后台检查，未发送串口指令或驱动小车。

## 手动结束本轮计时（2026-10-30，当前规则）

点击“回到初始位置”或“暂停显示”都会结束本轮并保留已用秒数。“恢复显示”只恢复串口显示，不续表；串口采集与原始日志保持接收。计时下方显示“本轮已结束”。下一次 KEY2 成功启动新一轮时从零起表；已结束的秒数在板上 RESET 等待期间也保留。实车普通停车、躲藏、纠偏与重规划仍继续累计。

后台协议版本为 round_timer_version=3；旧后台会提示重开。这些电脑按钮不向小车发送停止或复位指令。前后端离线检查覆盖结束、重复结束、恢复显示不续表、下一轮清零与失败提示；未按实车 KEY2 做新一轮试车。
