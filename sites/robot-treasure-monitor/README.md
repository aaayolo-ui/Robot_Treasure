# Robot Treasure 公网监控

站点身份保存在 `.openai/hosting.json`，默认仅所有者登录可访问。固定站点地址以Sites最终部署结果为准。

保留原激光/地图监控界面；本机Python服务解析真实串口数据，桥接程序每约1秒上传最新快照和最近800个轨迹点。网页不伪造离线数据，桥接10秒无上传后明确显示离线。

网页串口按钮通过云端命令队列交给本机服务执行，连上与否以电脑回传为准。命令15秒过期且绑定当前桥接会话，旧命令不会在重启后突然打开串口。断开操作关闭串口句柄，不向小车发送运动指令。串口默认断开，桥接程序不会自动连接串口。

云端仅保存最新快照、最近轨迹和最后一条串口/显示重置指令。显示重置不发送STM32指令。离线期间不能远程开关不在线电脑的串口。

本机桥接凭据保存在当前Windows用户LOCALAPPDATA下RobotTreasureMonitor/site.json，用Windows DPAPI加密；不包含于本站源码、浏览器、部署包或交接文件夹。更换电脑需要重新配置凭据。不要将仓库访问凭据写入文件。

启动本机监控后运行 `E:/Python/python.exe bridge/cloud_bridge.py`。程序通过本机8766接口读取快照，未直接打开串口；网页点击连接后才占用COM口。电脑关机时公网网页仍能访问，实时数据会显示离线。

验证：本机解析/投影及串口生命周期用例、桥接指令过期/重启/重复保护用例、正式构建与D1迁移；真实COM口和小车运动需用户实测，不自动驱动电机。
