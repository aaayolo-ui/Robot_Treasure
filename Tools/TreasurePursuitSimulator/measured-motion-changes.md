# 2026-10-07 实车参数接入与策略调整

本次只修改电脑仿真、验证工具及当前策略说明。未修改 STM32 工程、未烧录、未运行电机、未提交或推送 Git。工作区原有其他修改保留。

## 改动摘要

- 采用一辆车全图日志中的名义尺度速度：前进 0.674157 m/s、倒车 0.678733 m/s；转弯额外代价 0.768172 s；前进转倒车 0.282 s、倒车转前进 0.2735 s。
- 寻路、实际仿真运动和逃跑风险估计携带前进/倒车模式；倒车转弯后保持倒车，身体朝向用于红外方向解释。换向等待期间仍参与连续接触判定。
- 警方长直道搜索要求可维持三次采样的检测窗口，排除仅擦过探测半径边界的虚假覆盖收益，保持已经承诺的直道巡查。
- 连续逃跑经过安全筛选后优先走最近十秒未经过的路段，防止区域偏好导致短路段往返；迫近接触时仍允许紧急后退。
- 保留原七个场景，增加动作耗时 P90 的定点藏匿场景。两车暂共用一辆车数据，警方快 20% 是假设对照。

## 已执行验证

- `python -m unittest discover`：117 项通过，包括模式计时、连续接触、长直道承诺、检测边界和近期路线往返回归。
- `python simulate.py --seeds 1`：生成八个场景。单种子结果用于复盘，不代表胜率估计。
- `node qa/verify_annotations.cjs`：88 个节点、106 条路段、121 个原节点映射通过；道路与参考地图一致；内嵌数据与导出一致；八个场景均无继续接触帧、无五秒内 A-B-A-B 采样往返。
- `python validate_measured_route.py`：210 步同路线核对。实车 224.045 s、模型 219.710 s，低 1.93%；节点累计时间平均绝对误差 2.213 s。旧模型为 113.462 s。使用同一日志拟合和核对，属于样本内检查。
- 浏览器：默认节点编号显示；节点开关、路段开关、N023 详情、S001 详情、播放/暂停均有效。P90 场景显示 0.842/0.316/0.292 s；控制台无错误。截图见 `measured-motion.jpg`。
